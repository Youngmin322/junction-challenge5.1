# 공공데이터로 경상북도의 실제 문제 해결

## 팀 결정

- 2026-08-21 팀 논의 결과 Microsoft Korea × 경상북도 공공데이터 트랙을 우선 방향으로 선택했다.
- 구체 제품 주제는 아직 결정하지 않았다.
- 주제는 **실제 지역 문제**, **사용 가능한 공공데이터**, **3일 내 작동 가능한 프로토타입**을 함께 만족할 때 확정한다.

## 챌린지 핵심

공공데이터를 최소 1개 이상 사용해 경상북도의 실제 문제를 해결한다. 데이터 자체를 공개하는 데 그치지 않고 AI가 즉시 활용할 수 있도록 가공하거나, 공공데이터와 AI를 결합한 실제 서비스를 만든다.

## 두 가지 접근 방식

### 1. AI용 공공데이터 인프라

- 경상북도 관련 데이터 또는 경상북도 행정에 유용한 데이터를 AI 친화적으로 표준화
- 예시: MCP 서버, 오픈소스 스킬, 플러그인, 정제 API, 검색·질의 계층
- GitHub 공개와 오픈소스 라이선스 명시 필수

### 2. 지역 문제 해결 서비스

- 공공데이터를 이용해 경상북도의 실제 문제를 발견·분석
- AI 기반 서비스 또는 솔루션으로 사용자가 체감하는 결과 제공
- 인프라와 서비스 접근을 결합할 수 있음

## 결과물 조건

- 공공데이터 최소 1개 사용
- 실제 데이터 통합
- 비전문가도 배포하고 사용할 수 있는 Ready to Run 형태
- 단순 UI 목업이나 원본 데이터 노출을 넘는 가공·판단·행동
- 챗봇, 웹 앱, 모바일 앱, 대시보드, 라이브 데모 등 작동 프로토타입은 추가 점수 대상

권장 흐름:

> 공공데이터 수집 → 정제·결합 → AI 분석·판단 → 사용자 행동 → 효과 측정

## 평가 기준

| 항목 | 배점 |
| --- | ---: |
| 공공 가치·적용 가능성 | 35% |
| 기술적 우수성 | 25% |
| 혁신성·차별성 | 25% |
| 지속 가능성·확장성 | 15% |
| 작동 프로토타입 보너스 | 추가 10% |

공공 가치와 혁신성을 합하면 기본 평가의 60%다. 기술 복잡도보다 **구체 사용자의 실제 문제와 측정 가능한 지역 효과**를 먼저 설계한다.

> [!important] 2026-08-22 트랙 제공자 심사기준 확인
> 공공데이터를 클라우드에 저장하고 MCP Tool이 요청에 적합한 데이터를 검색·선별해 반환하는 구조도 MCP 활용으로 인정된다. 그러나 심사에서는 MCP 형식 사용 자체보다 **경상북도 문제를 얼마나 유용하게 해결하는지**, **다른 AI와 사용자가 결과를 신뢰하고 재사용할 수 있는지**를 함께 본다.

따라서 MCP는 가점용 외피가 아니라 다음 증거를 제공해야 한다.

1. **유용성:** 한울 해파리 관측·해류·확인구역 질문을 실제 Tool 호출로 해결한다.
2. **신뢰성:** 선택한 데이터와 제외한 데이터, 선택 이유, 출처·시각·품질·가정을 반환한다.
3. **재사용성:** Copilot 전용 응답이 아니라 다른 MCP 클라이언트도 같은 스키마와 run ID로 호출·재현할 수 있다.
4. **실패 투명성:** 데이터가 없거나 오래됐거나 방향을 검증하지 못하면 다른 숫자를 만들어 대체하지 않고 표준 오류로 중단한다.

## 주제 선정 기준

1. 경상북도에서 반복적으로 발생하는 불편·비용·위험인가?
2. 피해를 겪는 사용자를 한 문장으로 특정할 수 있는가?
3. 문제를 설명하거나 해결하는 공공데이터가 실제로 존재하는가?
4. 원본 데이터 조회를 넘어 AI가 수행할 판단이나 행동이 있는가?
5. 3일 안에 신뢰 가능한 핵심 흐름을 완주할 수 있는가?
6. 개선 효과를 시간·오류·비용·접근성 등의 지표로 측정할 수 있는가?
7. 해커톤 이후 유지·확장 경로를 설명할 수 있는가?

## 피해야 할 방향

- 데이터 연결이 없는 UI 목업
- 공공데이터를 그대로 보여주는 조회 화면
- 대상 사용자가 “경상북도 주민 전체”처럼 지나치게 넓은 문제 정의
- AI의 필요성이 없는 단순 필터·검색 서비스
- Microsoft/Azure 사용이 의무라고 근거 없이 가정하는 것
- 여러 분야와 데이터셋을 한 번에 해결하려는 과도한 범위
