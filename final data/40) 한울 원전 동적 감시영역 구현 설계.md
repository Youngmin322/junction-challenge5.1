# 한울 원전 동적 감시영역 구현 설계

> [!summary] 구현 결론
> 한울 공개형에서는 실제 취수구를 추정하지 않는다. `HB_0007 온양`, `HB_0008 덕천`, `HB_0009 나곡` 공개 해양관측점이 들어가는 ROMS 유효 해상격자를 **공개 감시게이트**로 삼고, 현재 또는 가정한 표층 입자가 6·12·24·48시간 안에 각 격자에 도달하는 앙상블 비율을 계산한다.

> [!warning] 제품의 정확한 이름
> **한울 연안 표층조건부 현장확인 후보영역**  
> `한울 취수구 도착확률`, `스크린 막힘확률`, `원전 정지위험 예보`가 아니다.

> [!warning] 제출까지 12시간 실행경계
> 원전 관계자·어민·관측기관의 신규 인터뷰나 기관 회신을 기다리지 않는다. 제출 전에는 트랙 제공자 검토, AI 데스크 리서치, 팀 블라인드 과업, 공개 API·계산 실패경로 테스트만 수행한다. 실제 운영구역·필요 선행시간·현장효과는 제출 후 검증부채다.

이 문서는 [[38) 동적 취수구 유입 위험영역 산정 설계]]을 한울용으로 고정한 실행 프로파일이다. 제품 상위 계약은 [[37) 원전 취수구 해파리 위험 대시보드 서비스 계획서]], 데이터 개통조건은 [[39) 데이터 부족 항목 전수조사와 수집 실행 결과]]를 따른다.

## 1. 한울 공개 프로파일

### 1.1 시설 대표정보

| 필드 | 공개형 값 | 용도·경계 |
|---|---|---|
| `story_site` | `HANUL` | 문제 맥락과 사용자 시나리오 |
| `public_site_label` | 한울원자력본부 | 시설명 표시 |
| `public_address` | 경상북도 울진군 북면 울진북로 2040 | KHNP가 공개한 홍보관·본부 안내 주소. 취수구 좌표가 아님 |
| `facility_geometry` | `null` | 공개형에서는 취수구·방류구·스크린을 디지타이징하지 않음 |
| `target_depth` | `surface_only` | 공개 ROMS가 표층장이므로 수중 해파리 전 수층 이동을 주장하지 않음 |
| `decision_use` | 현장확인 후보 수역 비교 | 자동 감발·정지·운전 권고 금지 |

KHNP 공식 시설현황상 한울 1–6호기와 신한울 1–2호기가 같은 본부 맥락에 있으나, 공개 감시게이트를 특정 호기나 취수구와 연결하지 않는다.

### 1.2 공개 해상 기준점

KHOA 공개 API 실응답과 NIFS 2025 해양조사연보에서 위치가 교차확인된 지점이다. NIFS 연보상 세 지점은 설치수심 2 m에서 수온·염분을 관측한다. KHOA API 실응답에서 유향·유속 필드가 관찰됐지만 지점별 센서 메타데이터·관측수심·방향 convention이 아직 공급자 문서로 확인되지 않았다. 제출 전에는 공급자 명세가 없을 경우 알려진 조류예보 시계열과 벡터 대조 검산을 조건부 통과경로로 사용하며 `공급자 미확인` 배지를 붙인다.

| 게이트 ID | 관측소 | 공개 좌표 | 공개형 역할 |
|---|---|---:|---|
| `G_ONYANG` | `HB_0007 / byyh3 한수원_온양` | 37.01944, 129.42500 | 남측 공개 감시게이트·2 m 수괴상태 관측점 |
| `G_DEOKCHEON` | `HB_0008 / bdch3 한수원_덕천` | 37.10000, 129.40416 | 중앙 공개 감시게이트·2 m 수괴상태 관측점 |
| `G_NAGOK` | `HB_0009 / bngh3 한수원_나곡` | 37.11916, 129.39583 | 북측 공개 감시게이트·2 m 수괴상태 관측점 |

> [!important] 좌표의 의미
> 세 좌표는 **해양관측소 좌표**다. 취수구 좌표, 특정 호기와의 대응관계, 취수 방향을 뜻하지 않는다. 화면에는 발전소 핀과 관측소 게이트 사이 연결선을 그리지 않는다.

기상 문맥은 KMA `22523 죽변` 연안부이를 사용한다. 기상청 공개 위치는 `37°06′10″N, 129°27′34″E`이며, 10분 주기로 파고·파주기·풍향·풍속·수온·기온·습도·기압을 제공한다. 이 지점에는 유속·염분이 없으므로 해류 검산점으로 쓰지 않는다.

## 2. 공개형과 운영형을 분리한다

| 프로파일 | 도착면 | 가능한 출력 | 금지 출력 |
|---|---|---|---|
| `HANUL_PUBLIC_DEMO` | HB 관측점이 포함된 ROMS wet cell | 표층조건부 게이트 연결비율·도착시간 분포·자료부족 | 취수구 유입·막힘·호기별 위험 |
| `HANUL_CACHED` | 검증 당시와 동일한 공개 게이트 | 과거 ROMS 실행 재생 | 현재 예보처럼 표현 |
| `HANUL_SYNTHETIC` | 동일 공개 게이트 | 북향·남향·역전 가상 유동 시연 | 실시간 자료와 합성장을 섞어 실제 예보처럼 표현 |
| `HANUL_OPERATOR` | KHNP가 승인한 비민감 `zone_id` 또는 제어단면 | 수심별 연결·현장확인 우선순위 | 승인 없이 좌표·형상 공개 |
| `HANUL_NEAR_FIELD` | 실제 취수 전방 제어단면·스크린 | 포획·유입 flux 연구 | 시설자료·검증 없이 활성화 |

공개 코드와 공개 데모 URL에는 `HANUL_PUBLIC_DEMO`까지만 포함한다. 운영형 형상은 공개 저장소에 넣지 않고, 보호된 환경에서 `zone_id`와 교차 결과만 외부 모듈에 반환하는 구조를 우선 협의한다.

## 3. 한울 공개 감시게이트 생성

### 3.1 기본 규칙

관측소 좌표 `sᵢ`가 들어가는 ROMS 유효 해상격자를 게이트로 사용한다.

$$
G_i=\operatorname{WetCell}_{ROMS}(s_i)
$$

1. ROMS 응답에서 각 관측점 좌표를 포함하는 격자를 찾는다.
2. 해당 셀이 결측·육지 셀이면 가장 가까운 유효 해상셀을 찾는다.
3. 이동거리가 해당 ROMS 격자 대각선 1개보다 크면 게이트를 만들지 않고 `blocked_gate_mapping`으로 기록한다.
4. `G_ONYANG`, `G_DEOKCHEON`, `G_NAGOK` 결과를 각각 보존한다. 합집합은 요약에만 사용한다.
5. 게이트는 실제 격자 polygon 전체다. 임의 반경이나 취수구 방향 타원을 만들지 않는다.

### 3.2 민감도

단일 wet cell 결과가 격자 선택에 종속될 수 있으므로 세 버전을 동시에 계산한다.

- `core`: 관측점이 포함된 단일 wet cell
- `edge4`: core와 변을 공유하는 유효 해상셀까지 포함
- `edge8`: core 주변 8방향 유효 해상셀까지 포함

대표값 하나를 고르지 않고 다음을 출력한다.

```text
connection_ratio_core
connection_ratio_edge4
connection_ratio_edge8
gate_spread = max(ratios) - min(ratios)
```

이 민감도는 공개 관측망 격자에 대한 것이며 실제 취수구 크기나 포획범위를 뜻하지 않는다.

### 3.3 계산영역

데이터 조회 bbox는 위험구역이 아니라 계산 창이다. 첫 호출은 세 관측점과 울진 연안을 충분히 포함하는 광역 발견창으로 시작하고, 다음 조건이면 자동 확장한다.

- 유효 입자의 1% 이상이 예측시간 전에 경계를 벗어남
- 연결등치선 또는 불확실성 띠가 bbox 경계에 닿음
- 시간보간에 필요한 다음 예보격자가 bbox 밖임

25%씩 확장해 다시 계산하며 API 허용범위·호출량을 넘으면 결과를 자르지 않고 `domain_insufficient`로 중단한다.

여기서 `1%`와 `25%`는 위험을 판정하는 과학적 임계값이 아니라, 해커톤 프로토타입이 계산영역 절단을 숨기지 않도록 둔 **버전 관리 가능한 공학 기본값**이다. 실행 결과에는 사용한 값을 함께 기록하고 이후 민감도 시험으로 조정한다.

## 5. 계산 활성화 Gate

이진 `LIVE/실패`가 아니라 항목별 상태와 허용 출력을 둔다.

| 검사항목 | `verified` | `unknown` | `failed` |
|---|---|---|---|
| ROMS 한울 공간커버리지 | 수송 계산 가능 | 지도에 격자만 표시, 수송 보류 | blocked |
| 유향 convention | 공급자 명세 또는 알려진 조류예보와의 벡터 대조 검산 통과. 검산만이면 `공급자 미확인` 배지 | 벡터 화살표·수송 금지 | blocked |
| 단위·좌표계·시간대 | 정규화 가능 | 원자료 카드만 | blocked |
| 예보 유효시각·연속성 | 해당 horizon 계산 | 확보된 horizon만 계산 | 해당 horizon blocked |
| forcing 메타데이터 | 포함항목 공개 | `current-only, forcing unknown` 배지 | 임의 바람·파랑 추가 금지 |
| HB 유속 메타·동시관측 | 센서수심·방향 확인 뒤 잔차 카드 | 수괴상태 카드만, 벡터 검산없음 | 수송 자체를 자동 차단하지 않음 |
| 관측 seed | 관측 조건부 실행 | 배경 연결지도만 | 허구의 현재 군집 생성 금지 |

현재 저장소 상태는 ROMS 신규 권한·한울 실응답이 없어 `HANUL_PUBLIC_DEMO = blocked/live`, `cached 또는 synthetic만 가능`이다. 활용승인 뒤 실제 raw response로 다시 판정한다.

## 6. 표층 입자추적 알고리즘

### 6.1 입력 정규화

유향이 물이 **향하는 방향**임을 공급자 명세 또는 조류예보 벡터 대조로 확인했을 때만 다음을 쓴다.

$$
u=s\sin\theta,\qquad v=s\cos\theta
$$

`from` convention이면 부호를 반대로 한다. convention 미확인 상태에서 눈으로 맞아 보이는 방향을 선택하지 않는다.

### 6.2 방출

- 배경 연결지도: 각 유효 해상격자를 5×5로 나눈 25개 고정 시작점
- 직접관측: 관측 footprint 안에서 관측 정확도에 맞게 방출
- 과거재현: 원본 관측시각·좌표가 통과한 기록만 사용
- 합성시연: `SYNTHETIC OBSERVATION` 워터마크를 붙인 별도 run

NIFS 주간 출현율은 입자 수나 가중치로 변환하지 않는다.

### 6.3 적분과 중단

기준선은 시간·공간 보간된 ROMS 표층류만 쓰고 Heun 또는 RK4로 적분한다.

```python
dt_s = min(600, 0.25 * grid_spacing_m / max(max_speed_ms, 1e-6))
```

- 결측 이웃셀: 최근접값으로 채우지 않고 `field_missing`
- 해안선과 교차: 기준선에서는 `beached`로 종료
- 경계 밖: `out_of_domain`
- 유효시각 부족: 해당 horizon `forecast_unavailable`
- 게이트 polygon 진입: `gate_hit`, 최초 도착시각 저장

해안 부근 결과가 경계 처리에 지배되는지 보기 위해 `beached`, `reflect`, `remain_at_coast` 세 규칙을 별도 민감도 run으로 계산할 수 있다. 대표 화면은 보수적으로 서로 일치하는 셀과 규칙에 따라 달라지는 셀을 분리한다.

### 6.4 산출식

$$
C_{i,h}=\frac{N(\text{valid particles hitting }G_i\text{ within }h)}{N(\text{valid particles released})}
$$

```text
connection_ratio = gate_hit_count / valid_count
coverage_ratio   = valid_count / released_count
arrival_p10_h, arrival_p50_h, arrival_p90_h
boundary_rule_spread
gate_spread
```

`Cᵢ,ₕ`는 모델·초기위치·표층가정·게이트에 조건부인 비율이다. 독립 사건라벨로 교정되기 전에는 실제 사건확률이 아니다.

## 7. 한울 특화 물리 경고

### 7.1 표층과 수중은 반대일 수 있다

한국 동해안은 남풍·남서풍 계열이 지속될 때 연안 용승이 발생할 수 있다. 표층은 외해 방향인데 저층은 연안 방향으로 보상 유입하는 조건이 생길 수 있다. 노무라입깃해파리가 40–60 m에 주로 관측된 연구결과와 결합하면, 표층 결과만으로 `멀어지므로 안전`이라고 말할 수 없다.

따라서 다음 중 하나면 화면 상단에 `UPWELLING / VERTICAL-FLOW BLIND SPOT` 배너를 고정한다.

- 남풍·남서풍 지속과 연안 저수온이 함께 나타남
- KHNP 취수 수온과 KMA 죽변 표층 수온의 차이가 비정상적으로 커짐
- 표층 연결은 낮지만 수심별 유속·염분·밀도 자료가 없음

현재 공개자료로 위 조건의 정량 임계값을 교정하지 않았으므로 경고는 `가능한 해석상 공백`이지 용승 확정판정이 아니다.

### 7.2 수온은 위험 가중치가 아니다

수온은 지도·시계열 문맥으로만 표시한다. 노무라입깃해파리 현장연구에서는 염분·해수밀도와 양의 관련성이 있었지만 수온 관계는 유의하지 않았다. 수온 레이어에는 `종의 존재·도달 가능성을 단독 판정하지 않음`을 함께 표시한다.

### 7.3 시설 근접영역은 공개모델의 공백이다

취수·배수와 온배수 재순환은 근접 유동을 바꿀 수 있지만 공개 ROMS와 150 m 수심으로는 재현할 수 없다. 공개 관측점 게이트를 통과한 뒤 실제 취수구까지의 궤적은 계산하지 않는다.

## 8. 한울 화면

### 8.1 지도 레이어

1. `관측`: 직접·과거·합성의 출처와 관측시각
2. `물리 연결`: 6·12·24·48시간별 `Cᵢ,ₕ`
3. `관측범위`: 실제 노력량·경로가 있을 때만 표시, 없으면 `분모 없음`
4. `자료부족`: ROMS 결측, 수심 미측정, domain exit
5. `환경문맥`: 죽변 풍랑·수온, KHNP 공개 취배수 수온·염분
6. `공개 감시게이트`: 온양·덕천·나곡 ROMS wet cell

레이어를 곱해 단일 위험점수를 만들지 않는다.

```text
depth: SURFACE_ONLY
direction_convention: VERIFIED | UNKNOWN | FAILED
forcing_metadata: VERIFIED | UNKNOWN

gate_mapping: core | edge4 | edge8
valid_particle_ratio
domain_exit_ratio
data_gaps[]
```

### 8.3 워터마크

> **표층 수동입자 가정에 따른 공개 해양관측점 도달 가능 영역이며, 실제 취수구 유입·막힘·원전 위험 예측이 아닙니다.**

`DEMO` 한 단어만 사용하지 않는다.

## 9. 사용자 예시의 한울 판정

가상 군집이 `G_DEOKCHEON` 남쪽에 있고 ROMS 표층류가 더 남쪽으로 흐르는 경우:

1. 6시간 `C_DEOKCHEON`이 낮으면 `현재 표층조건에서 단기 연결 낮음`으로 표시한다.
2. 12·24·48시간 동안 유향이 바뀌면 각 시간창의 연결영역을 새로 계산한다.
3. 저수온은 연결비율을 낮추거나 0으로 만들지 않는다.
4. 남풍 지속·연안 저수온이면 용승 공백 배너를 띄운다.
5. 결론 문구는 다음으로 제한한다.

> 현재 표층 흐름에서는 해당 관측과 덕천 공개 관측점 게이트의 단기 연결성이 낮습니다. 그러나 수심별 흐름, 용승 가능성, 취수 근접유동이 측정되지 않아 실제 취수구 안전 판정에는 사용할 수 없습니다.
