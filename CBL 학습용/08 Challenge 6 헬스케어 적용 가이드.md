## 2. 현재 CBL 단계 진단

현재는 **Engage 후반–Investigate 초중반**으로 보는 것이 타당하다.

확보한 것:

- 헬스케어라는 Big Idea
- 퇴원 이후의 연속성이라는 문제 방향
- 초기 병원 접점 후보
- 개별 의료진 중심의 현실적인 협력 전략
- 팀 Norms와 코어 타임의 일부

아직 부족한 것:

- 대상 환자군·보호자·의료진·기관 중 우선 맥락
- 실제 퇴원 준비와 후속 관리의 현재 여정
- 간극의 원인, 규모, 빈도, 영향
- 기존 해결 방식과 실패·우회 패턴
- 해결 기준과 평가 지표
- 기관 승인, 환자 연구, 데이터 처리의 정확한 경로

따라서 지금 핵심 성과는 앱 기능 목록이 아니라 **신뢰할 수 있는 문제 지도와 검증 가능한 Challenge**다.

## 3. 임시 프레이밍

### Big Idea

`퇴원 이후에도 돌봄이 안전하고 연속적으로 이어지는 경험`

### Essential Question 후보

> 병원에서 일상으로 전환하는 사람들은 어떻게 필요한 돌봄을 이해하고 이어갈 수 있을까?

### Challenge 후보

> 우리는 지역 의료 맥락에서 퇴원 이후 돌봄의 단절이 발생하는 지점과 원인을 이해하고, 환자·보호자·의료진의 부담을 늘리지 않으면서 다음 행동의 연속성을 돕는 안전한 방법을 검증한다.

이 문장은 임시다. 다음을 확인한 뒤 좁힌다.

- 어떤 퇴원 상황인가: 수술, 만성질환, 재활, 약물, 검사 후 관리 등
- 가장 큰 영향을 받는 사람은 누구인가?
- “단절”은 정보 이해, 행동 수행, 연락, 예약, 인계, 역할, 접근성 중 무엇인가?
- 팀의 시간 안에 실제로 관찰·검증 가능한 변화는 무엇인가?

## 4. 사실·해석·가정 분리

| 구분 | 내용 | 처리 방식 |
|---|---|---|
| 내부 사실 | 팀은 퇴원 후 돌봄의 간극을 탐색 방향으로 논의했다 | 결정 로그에 보존 |
| 내부 사실 | 병원 전체보다 개별 의사 협업이 현실적이라는 멘토 의견이 있었다 | 전문가 의견으로 표시 |
| 내부 사실 | S-Pohang Hospital을 첫 접점으로 고려했다 | 접촉 목적과 권한 확인 |
| 해석 | 퇴원 후 정보 전달이 핵심 원인일 수 있다 | 의료진·문헌·경험 자료로 검증 |
| 가정 | 환자·보호자가 다음 행동을 이해하지 못한다 | 당사자 연구 전 안전한 대리 검증 + 승인 경로 탐색 |
| 가정 | 디지털 도구가 간극을 줄일 수 있다 | 비디지털 대안과 함께 비교 |
| 가정 | 의료진의 추가 업무 없이 운영 가능하다 | 업무 흐름 지도와 역할극으로 검증 |
| 가정 | 한 병원의 문제 구조가 다른 병원에도 적용된다 | 기관별 맥락 차이 확인, 일반화 제한 |
| 미확인 | 재활 영역과 현재 프레이밍의 중복·차별성 | 기존 서비스·부서·연계 구조 조사 |

## 5. 다음 Investigate의 우선 질문

### P0 — 안전·권한: 다른 활동의 선행 조건

1. Academy 차원에서 환자·보호자·병원 직원 연구에 적용되는 절차는 무엇인가?
2. 인터뷰, 관찰, 사용성 테스트, 실제 서비스 적용 중 어떤 활동이 연구윤리 심의 또는 기관 승인을 요구하는가?
3. 건강 정보·개인정보·사진·음성을 수집하지 않고도 답할 수 있는 질문은 무엇인가?
4. 병원 담당자의 개인 의견과 기관의 공식 승인·파트너십은 어떻게 구분되는가?

### P1 — 현재 여정과 문제 존재

1. 퇴원 결정 전부터 귀가 후 첫 후속 관리까지 실제 단계는 어떻게 이어지는가?
2. 각 단계에서 환자·보호자·간호사·의사·재활·원무·지역 기관의 역할은 무엇인가?
3. 정보·책임·결정이 끊기는 지점은 어디인가?
4. 현장은 어떤 임시방편과 기존 도구를 사용하는가?
5. 문제가 발생한 사실을 조직은 어떤 지표나 사건으로 알게 되는가?

### P2 — 대상과 맥락

1. 모든 퇴원이 같은 어려움을 갖는가, 특정 환자군·절차·시점에 집중되는가?
2. 디지털 접근성, 건강 문해력, 보호자 유무, 지역 거리, 언어가 경험을 어떻게 바꾸는가?
3. 문제의 영향을 직접 받지만 현재 접근하기 어려운 집단은 누구인가?
4. 재활 영역과 겹치는 부분, 현재 서비스가 맡고 있는 부분은 무엇인가?

### P3 — 해결 기준과 평가

1. 환자·보호자에게 “연속성 향상”은 어떤 관찰 가능한 행동인가?
2. 의료진에게 허용 가능한 추가 업무와 위험 수준은 무엇인가?
3. 이해도·행동·연락·업무 부담·안전 중 초기 프로토타입이 측정할 수 있는 것은 무엇인가?
4. 어떤 결과가 나오면 방향을 중단하거나 전환해야 하는가?

## 6. 안전한 조사 사다리

낮은 위험에서 높은 위험으로 단계적으로 이동한다.

### 1단계 — 공개 자료와 시스템 이해

- 학술 연구, 정부·공공기관 자료, 병원 공개 안내
- 퇴원 교육·전환기 돌봄·재활·지역 연계의 기존 모형
- 국내 개인정보·연구윤리·디지털 헬스 관련 규정

가능한 결론: 알려진 문제 유형, 조사 질문, 용어, 제도 구조  
불가능한 결론: 특정 병원·환자 집단의 실제 경험

### 2단계 — 비식별 전문가 자문

- 의료진, 간호, 재활, 의료사회복지, 원무, 병원 IT·개인정보·IRB 담당자
- 환자 사례나 식별 정보를 요청하지 않고 일반적인 업무 흐름·장벽·승인 경로를 질문

가능한 결론: 현장 가정의 타당성, 역할·제약·위험 후보  
불가능한 결론: 전체 의료진의 대표 의견, 환자 욕구의 확정

### 3단계 — 대리 사용자·합성 시나리오

- 퇴원 경험이 있는 일반 성인이 자발적으로 공개 가능한 범위에서 과거 경험을 말하는 탐색은 기관 지침 확인 후 진행
- 더 보수적으로는 가상 페르소나와 합성 사례로 언어·흐름·개념을 검토

가능한 결론: 표현 이해, 정보 구조, 과제 흐름의 초기 문제  
불가능한 결론: 임상 효과, 실제 취약 환자의 사용성

### 4단계 — 공식 승인된 실제 대상 연구

- 명확한 연구계획, 모집·동의, 최소 데이터, 위험 통제, 보관·삭제
- Academy와 기관의 요구에 따라 IRB 등 공식 판단

가능한 결론: 승인된 표본·맥락 안의 실제 경험과 사용성  
불가능한 결론: 설계 범위를 넘는 일반화

### 5단계 — 승인된 제한적 구현

- 임상·운영 책임자, 오류 대응, 데이터 관리, 사전 지표, 중단 조건
- 실제 업무와 환자 안전에 영향을 주는 경우 별도 검토

가능한 결론: 해당 현장에서의 운영 가능성과 초기 영향  
불가능한 결론: 충분한 비교·기간 없이 임상적 효과 주장

> [!warning] 단계 건너뛰기 금지
> “교육 프로젝트”, “프로토타입”, “비상업적”이라는 이유만으로 환자 접촉·건강 정보 처리·의료 현장 적용이 자동 허용되는 것은 아니다.

## 7. S-Pohang Hospital 첫 만남의 목표

첫 만남의 목표는 솔루션 판매나 협업 확정이 아니다.

### 확인할 것

- 일반적인 퇴원 준비와 후속 관리의 큰 흐름
- 병원이 이미 중요하게 보는 문제와 지표
- 현장에서 빈번하거나 영향이 큰 단절 지점
- 환자 사례를 드러내지 않고 설명 가능한 업무 장벽
- 관련 부서·직군·기존 프로젝트
- 자문, 연구, 프로토타입 검토, 실제 적용 각각의 공식 경로
- 다음에 만나야 할 사람과 요청 방식

### 공유할 것

- Academy 러너 팀이라는 정체성과 학습 목적
- 현재 임시 프레이밍과 아직 모르는 것
- 환자 정보나 진료 기록을 요청하지 않는다는 원칙
- 당장 앱을 제안하지 않고 문제를 이해하려는 이유
- 논의 내용을 어떻게 기록·인용·공유할지

### 묻지 말아야 할 것

- 식별 가능한 환자 사례
- 내부 문서·데이터의 무단 제공
- 비공식 자리에서의 환자 모집
- 검토되지 않은 의료 콘텐츠의 사용 요청
- 담당자가 권한이 없는 기관 차원의 약속

## 8. 첫 만남 질문안

1. 한 사람이 퇴원을 준비한다는 결정부터 집에서 다음 돌봄을 이어가기까지, 일반적인 흐름을 단계별로 설명해 주실 수 있나요?
2. 각 단계에서 누가 무엇을 책임지고, 어떤 정보나 도구를 사용하나요?
3. 계획대로 잘 이어지는 경우와 그렇지 않은 경우는 무엇이 다른가요?
4. 환자·보호자가 자주 되묻거나 놓치는 지점은 어디인가요? 개인 사례 정보 없이 일반적인 패턴만 부탁드립니다.
5. 의료진 또는 직원이 추가로 확인·수정·우회하는 일은 무엇인가요?
6. 현재 사용하는 안내, 연락, 예약, 지역 연계 방식은 무엇이며 어떤 한계가 있나요?
7. 재활 또는 다른 부서·기관과 책임이 겹치거나 끊기는 지점이 있나요?
8. 이 문제를 병원은 어떤 사건이나 지표로 인식하나요?
9. 저희가 현재 잘못 이해했거나 과도하게 단순화한 부분은 무엇인가요?
10. 다음 단계로 자문·관찰·프로토타입 검토를 원한다면 각각 어떤 공식 절차와 담당자를 거쳐야 하나요?

유도 질문인 “이런 앱이 있으면 좋겠나요?”는 뒤로 미룬다.

## 9. 만남 직후 내려야 할 결정

|---|---|---|
| 문제가 실제로 중요한가 | 지지 / 반박 / 불충분 | 근거와 한계를 기록하고 추가 관점 선택 |
| 가장 유망한 대상·시점은 무엇인가 | 좁힘 / 유지 / 전환 | Challenge 문장 갱신 |
| 우리 프레이밍과 병원 우선순위가 맞는가 | 정렬 / 부분 정렬 / 비정렬 | 공동 영역 또는 독립 탐색 결정 |
| 다음 관계 수준은 무엇인가 | 추가 자문 / 담당자 연결 / 중단 | 개인 의견과 기관 승인 구분 |
| 안전한 다음 활동은 무엇인가 | 공개자료 / 전문가 / 대리테스트 / 공식연구 | 필요한 승인부터 확보 |

다음 단계에 대한 구체적 책임자·기한·완료 기준이 없으면 “좋은 미팅”으로 끝난다.

## 10. 조사 결과로 만들어야 할 시스템 지도

최소 다음 요소를 한 장에 표현한다.

- 시간: 퇴원 전 → 퇴원 순간 → 귀가 직후 → 첫 후속 관리
- 행위자: 환자, 보호자, 병동, 외래, 재활, 약국, 지역 기관 등
- 정보: 어떤 정보가 누구에게서 누구에게 이동하는가?
- 행동: 각자가 해야 할 다음 행동은 무엇인가?
- 책임: 확인·오류·연락의 책임은 누구에게 있는가?
- 접점: 종이, 대화, 전화, 문자, 앱, EMR 등
- 단절: 대기, 중복, 누락, 오해, 접근 불가, 책임 공백
- 제약: 시간, 인력, 규정, 기술, 비용, 문해력
- 결과: 단절이 만들어내는 행동·업무·안전 영향

지도에는 `관찰된 사실`, `전문가 의견`, `팀 가정`을 색이나 라벨로 구분한다.

## 11. 해결 기준 초안

Investigate에서 수정할 가설적 기준이다.

- 환자·보호자가 다음 행동과 문의가 필요한 상황을 구분할 수 있어야 한다.
- 의료진의 반복 설명·추가 입력·사후 확인 부담을 무리하게 늘리지 않아야 한다.
- 기존 퇴원·예약·연락 흐름과 충돌하지 않아야 한다.
- 의료 조언의 출처와 책임이 명확해야 한다.
- 디지털 접근성이 낮아도 핵심 경로에서 배제되지 않아야 한다.
- 필요 이상의 건강·개인정보를 수집하지 않아야 한다.
- 실패·누락·오해가 발생했을 때 안전한 대체 경로가 있어야 한다.
- 특정 병원·개인의 선의가 없으면 유지되지 않는 구조를 피해야 한다.
- 초기 실험에서 관찰 가능한 지표가 있어야 한다.

이 기준은 실제 사용자·의료진·운영·안전 관점의 근거가 확보되어야 확정된다.

## 12. 안전한 초기 프로토타입 후보

솔루션 선택이 아니라 **검증 형식의 후보**다.

| 질문 | 프로토타입 | 대상 | 측정 | 금지선 |
|---|---|---|---|---|
| 문제 흐름이 맞는가 | 서비스 여정·블루프린트 | 의료진·운영 전문가 | 누락 역할·단절·오류 | 환자 사례 정보 수집 금지 |
| 언어가 이해되는가 | 합성 내용의 종이 안내 | 일반 성인 대리 참여자 | 다음 행동 설명·오해 | 실제 의료 지침처럼 사용 금지 |
| 정보 구조가 작동하는가 | 클릭형 프로토타입 | 대리 참여자 | 과제 완료·시간·우회 | 계정·건강 정보 입력 금지 |
| 업무 흐름에 맞는가 | 역할극·Wizard of Oz | 팀+의료진 검토 | 추가 업무·책임 공백 | 실제 환자 적용 금지 |
| 기술 병목이 있는가 | 합성 데이터 기술 스파이크 | 팀 | 정확성·응답·오류 | 실제 진료 데이터 금지 |

## 13. 추천하는 2주 학습 스프린트

### 스프린트 목표

> 퇴원 이후 돌봄의 단절이 발생하는 구체적 지점·행위자·원인을 최소 두 종류의 근거로 확인하고, 안전한 초기 검증을 위한 대상·해결 기준·승인 경로를 결정한다.

### 1주차 — 문제 구조와 권한

| 날 | 핵심 행동 | 산출물 |
|---|---|---|
| 월 | 현재 가정·GQ·금지선 합의 | 가정 지도, 질문 백로그 |
| 화 | 공개 자료와 기존 해결 조사 | 출처 카드, 기존 해결 표 |
| 수 | 병원/의료진 접촉 준비 또는 인터뷰 | 자문 계획, 동의·기록 범위 |
| 목 | 업무 흐름 자문·전문가 검토 | 비식별 기록, 사실/해석 분리 |
| 금 | 증거 통합과 반대 사례 리뷰 | 시스템 지도 v1, 결정 로그 |

### 2주차 — 범위와 초기 실험

| 날 | 핵심 행동 | 산출물 |
|---|---|---|
| 월 | 대상·시점·Challenge 좁히기 | Challenge v2, 제외 범위 |

### 스프린트 종료 게이트

- [ ] 특정 단절 지점과 영향을 받는 대상이 한 문장으로 설명된다.
- [ ] 결론마다 내부 논의 외의 근거가 최소 하나 이상 있다.
- [ ] 의료진 관점과 다른 관점의 누락이 명시되어 있다.
- [ ] 기존 해결과 재활 영역의 중복·차이가 정리되어 있다.
- [ ] 안전·개인정보·기관 승인 경로를 확인할 다음 담당자가 있다.
- [ ] 해결 기준과 가장 위험한 가정이 합의되었다.
- [ ] 실제 환자나 건강 데이터 없이 수행 가능한 다음 실험이 있다.
- [ ] 팀이 계속·좁힘·전환 중 하나를 결정했다.

## 14. 팀 역할 제안

역할은 주 단위로 순환하되 책임자는 명확히 한다.

- 학습 리드: Challenge·GQ·게이트 관리
- 연구 리드: 출처·인터뷰·분석 품질
- 이해관계자 리드: 연락·약속·후속·관계 수준
- 안전 리드: 동의·개인정보·기관 승인·중단 조건
- 프로토타입/실험 리드: 가설·판정 기준·세션 일관성
- 기록 리드: 원자료·결정 로그·성찰·공유

팀 규모가 작으면 한 사람이 여러 역할을 맡되, 안전 검토와 실험 진행은 가능하면 분리한다.

## 15. 의료·연구·개인정보 안전선

### 하지 않는다

- 승인 없이 환자나 치료 관계에 있는 사람을 모집한다.
- 환자 이름, 연락처, 병명, 기록, 화면 등 식별·건강 정보를 요청한다.
- 의료진이 말한 개별 사례를 상세히 기록하거나 외부 공유한다.
- 검토되지 않은 콘텐츠를 의료 지침처럼 제시한다.
- 프로토타입이 진단·치료·위기 대응을 대신한다고 표현한다.
- 개인 의료진의 호의를 기관 승인이나 협약으로 표현한다.
- 사용성 신호를 임상 효과로 주장한다.

### 사전에 공식 확인한다

- 환자·보호자·직원 대상 연구나 관찰
- 건강·개인정보 수집, 녹음, 촬영, 클라우드 저장
- 병원 공간·이름·로고·내부 문서 사용
- 실제 업무 흐름과 환자 행동에 영향을 주는 파일럿
- 생성형 AI, 외부 API, 분석 도구로 민감 정보를 전송하는 행위

> [!danger] 확인 주체
> 실제 활동 전 Academy 담당자와 해당 병원의 IRB·개인정보·임상·정보보안 책임자에게 구체적인 연구계획을 제시해 판단받는다. 이 문서는 법률·의료·기관 승인을 대신하지 않는다.

## 16. 프로젝트 주장의 수준표

| 확보한 증거 | 말할 수 있는 것 | 말하면 안 되는 것 |
|---|---|---|
| 공개 자료 | 선행연구에서 보고된 문제 | 우리 병원에서도 동일하다 |
| 의료진 한 명 자문 | 그 역할·맥락의 전문가 의견 | 모든 의료진·환자가 동의한다 |
| 대리 사용자 테스트 | 합성 과제에서의 초기 사용성 | 실제 환자에게 안전·효과적이다 |
| 공식 승인된 실제 사용자 연구 | 해당 표본·조건의 관찰 결과 | 전체 환자군에 일반화된다 |
| 제한된 현장 파일럿 | 해당 기간·현장의 운영 결과 | 임상 결과가 인과적으로 개선됐다 |

최종 발표에서 이 표를 사용하면 과장과 오해를 줄일 수 있다.

## 17. 최종적으로 내려야 할 결론

Challenge 6이 끝날 때 최소 다음을 답한다.

1. 어떤 퇴원 맥락에서 누구의 어떤 단절을 다뤘는가?
2. 문제의 존재와 원인을 어떤 자료와 관점으로 확인했는가?
3. 누락된 관점과 일반화할 수 없는 범위는 무엇인가?
4. 기존 해결은 무엇이며 왜 충분하지 않거나 다른가?
5. 해결안의 기준과 금지 조건은 무엇인가?
6. 가장 위험한 가정은 무엇이었고 어떻게 검증했는가?
7. 결과는 무엇을 지지·반박했고 무엇은 여전히 모르는가?
8. 환자·의료진·기관에 예상되는 가치와 부담·위험은 무엇인가?
9. 실제 적용 전에 필요한 승인·파트너·근거·자원은 무엇인가?
10. 팀과 각 러너의 판단·협업·기술·윤리 역량은 어떻게 변했는가?
