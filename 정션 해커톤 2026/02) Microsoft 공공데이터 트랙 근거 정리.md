# Microsoft 공공데이터 트랙 근거 정리

## 조사 범위

- 자료: `JunctionX Korea 2026.pptx` Google Slides, 14장
- 주관: Microsoft Korea
- 주제: 경상북도 공공데이터를 활용한 지역 혁신
- `확인`: 공식 슬라이드에 직접 표시
- `추측`: 확인 사실을 바탕으로 한 전략적 해석
- `미확정`: 슬라이드만으로 판단할 수 없음

> [!warning] 근거 사용 원칙
> 최신 현장 공지와 운영진 안내가 슬라이드보다 우선한다. 사례로 제시된 MCP·지도·법령 저장소를 필수 기술로 확대 해석하지 않는다.

## 슬라이드별 핵심 근거

| 슬라이드 | 확인 내용 |
| ---: | --- |
| 1 | 트랙 제목: Unlocking Local Innovation Through Public Data |
| 2 | 공개된 데이터를 AI가 즉시 사용할 수 있게 만드는 것을 남은 과제로 제시 |
| 4~6 | 법령 Git 저장소, 법령 MCP 서버, 실시간 그늘길 지도를 사례로 제시 |
| 9 | 경상북도의 실제 문제 해결, 공공데이터 최소 1개 사용 |
| 10 | 데이터 인프라와 지역 문제 해결 서비스 두 접근, 결합 가능 |
| 10~11 | 인프라 방식은 GitHub 공개와 오픈소스 라이선스 명시 |
| 11 | Ready to Run, 실제 데이터 통합, 작동 프로토타입 권장 |
| 11 | 단순 UI 목업과 원본 데이터 단순 노출 지양 |
| 11 | 우수 프로젝트를 경상북도 저장소로 이관해 운영할 계획 |
| 12 | 기술 25%, 공공 가치 35%, 혁신 25%, 지속 가능성 15%, 프로토타입 보너스 10% |

## 평가 해석

- 기본 배점에서 공공 가치·적용 가능성이 35%로 가장 높다.
- 공공 가치 35%와 혁신성 25%를 합치면 60%이므로 문제 발견과 차별화가 핵심이다.
- 기술적 우수성은 복잡한 기술의 수보다 AI와 공공데이터를 타당하게 사용했는지가 중요하다.
- 지속 가능성에는 유지보수, 장기 운영, 다른 지역·분야로의 확장 가능성이 포함된다.
- 프로토타입 보너스는 작동하는 챗봇·웹 앱·대시보드·서비스 등에 적용되지만 정확한 총점 합산 방식은 미확정이다.

## 확인된 사례의 의미

| 사례 | 시사점 | 필수 여부 |
| --- | --- | --- |
| 법령 Git 저장소 | 공공데이터를 재사용 가능한 공공 자산으로 전환 | 선택 사례 |
| 법령 MCP 서버 | AI가 바로 읽고 사용할 수 있는 인터페이스 제공 | 선택 사례 |
| 실시간 그늘길 지도 | 데이터가 시민이 체감하는 행동으로 연결 | 선택 사례 |

## 공식 자료에서 확인되지 않은 사항

- Microsoft 또는 Azure 기술 사용 의무와 가산점
- 공공데이터로 인정되는 기관·라이선스의 정확한 범위
- 경상북도 외 전국 데이터의 사용 조건
- 서비스 방식의 GitHub 공개 의무
- 프로토타입 보너스의 총점 합산 방식
- 제출 형식, 배포 URL, 발표 데모 필수 범위
- 최종 제출 마감 시각
- 경상북도 저장소 이관 시 코드 소유권·운영 책임·라이선스
