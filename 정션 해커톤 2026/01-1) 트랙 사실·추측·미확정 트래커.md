# 트랙 사실·추측·미확정 트래커

## 상태 기준

| 상태 | 의미 |
| --- | --- |
| 확인 | 발표·이미지·공식 문서에서 직접 확인 |
| 부분 확인 | 복수 자료의 표현이 다르거나 세부 조건이 빠짐 |
| 추측 | 확인된 사실을 바탕으로 한 해석이며 공식 확인 전 |
| 미확정 | 현재 자료만으로 판단 불가 |

## 요구사항 및 평가

| 항목 | 상태 | 현재 근거 또는 판단 | 다음 확인 |
| --- | --- | --- | --- |
| AI:GO 에이전트 스쿼드 기능을 핵심 기반으로 사용 | 확인 | 챌린지 이미지 설명 | 구현 인정 범위 |
| 수학·코딩을 포함한 여러 범주의 문제 대응 | 확인 | 챌린지 이미지 및 발표 전사 | 실제 범주 목록 |
| 제공 모델 후보와 일부 크기 | 부분 확인 | PDF Slides 72·74·84·86에서 7개 모델명 확인 | 대회에서 실제 선택 가능한 전체 목록과 단가 |
| 에이전트별 도구 구성 가능 | 확인 | 발표 전사 | 허용 도구와 샌드박스 제약 |
| 자동 벤치마크 평가 | 확인 | PDF Slide 96, 40점 | 정확한 점수 변환식 |
| 시각화 평가 | 확인 | PDF Slide 96, 30점과 6개 평가 관점 | 정성 평가 세부 루브릭 |
| 인터랙티브 시각화 제출이 필수 | 확인 | PDF Slide 87의 두 번째 결과물. 발표 전사와 표현 차이 존재 | 최종 제출 형식 |
| 토큰 효율성 평가 | 확인 | PDF Slide 96, 30점 | 비용을 점수로 바꾸는 산식 |
| 테스트 실행은 비용의 1/5만 반영 | 확인 | PDF Slide 96 | 모델별 기준 단가 |
| 정식 제출 비용은 100% 반영되고 모든 제출이 누적 | 확인 | PDF Slide 96 인용 세부정보 | 실패 실행도 동일한지 |
| Squad Template JSON 1개와 트랙별 one-shot prompt 1개 제출 | 확인 | PDF Slide 83 캡처 | JSON 스키마와 예제 |
| 템플릿 Checking은 무료·무제한 | 확인 | PDF Slide 83 캡처 | 실제 대회 포털에서 최신 상태 확인 |
| 제출 Queue는 동시 실행 1개·대기 3개 | 확인 | PDF Slide 83 캡처 | 실제 대회 포털에서 최신 상태 확인 |
| 평가 문제가 사전에 미공개 | 미확정 | 공식 표현 없음 | 공개 범위와 테스트 방식 |
| 비공개 테스트 케이스가 존재 | 추측 | 자동 채점과 일반성 요구에서 추론 | 운영진 확인 |
| 실행마다 문제가 달라짐 | 미확정 | 근거 없음 | 제출 방식 확인 |
