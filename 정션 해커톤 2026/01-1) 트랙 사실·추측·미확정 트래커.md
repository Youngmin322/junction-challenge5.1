# 트랙 사실·추측·미확정 트래커

## 상태 기준

| 상태 | 의미 |
| --- | --- |
| 확인 | 발표·이미지·공식 문서에서 직접 확인 |
| 부분 확인 | 복수 자료의 표현이 다르거나 세부 조건이 빠짐 |
| 추측 | 확인된 사실을 바탕으로 한 해석이며 공식 확인 전 |
| 미확정 | 현재 자료만으로 판단 불가 |

## 요구사항 및 평가

| 항목 | 상태 | 현재 근거 또는 판단 | 다음 확인 |
| --- | --- | --- | --- |
| 공공데이터 최소 1개 사용 | 확인 | 공식 슬라이드 9~11 | 인정 데이터 범위 |
| 데이터 인프라와 지역 문제 해결 서비스 중 하나 이상 선택 | 확인 | 공식 슬라이드 10 | 결합형 평가 방식 |
| 인프라 방식은 AI가 즉시 쓸 수 있는 표준화 결과물 지향 | 확인 | MCP 서버·오픈소스 스킬·플러그인 예시 | 필수 인터페이스·표준 여부 |
| 인프라 방식은 GitHub 공개와 라이선스 명시 필수 | 확인 | 공식 슬라이드 10~11 | 허용 라이선스와 이관 조건 |
| 서비스 방식은 경상북도 지역 문제 해결이 목적 | 확인 | 공식 슬라이드 9~10 | 전국 데이터 활용 인정 범위 |
| 실제 데이터 통합 없이 UI 목업만 제출 | 불가 | 공식 슬라이드 11의 Avoid 항목 | 실제 데이터 판정 기준 |
| 원본 데이터 단순 노출 | 불가 | 공식 슬라이드 11의 Avoid 항목 | 요구되는 가공 수준 |
| 비전문가도 배포·사용하기 쉬운 Ready to Run 결과물 | 확인 | 공식 슬라이드 11 | 배포 URL·설치 문서 요구 여부 |
| 기술적 우수성 | 확인 | 공식 슬라이드 12, 25% | 세부 루브릭 |
| 공공 가치·적용 가능성 | 확인 | 공식 슬라이드 12, 35% | 효과 측정 방식 |
| 혁신성·차별성 | 확인 | 공식 슬라이드 12, 25% | 비교 대상 범위 |
| 지속 가능성·확장성 | 확인 | 공식 슬라이드 12, 15% | 운영 계획 요구 수준 |
| 작동 프로토타입 보너스 | 부분 확인 | 공식 슬라이드 12, 10% | 기본 100점 외 가산인지 확인 |
| Microsoft 또는 Azure 기술 사용 필수 | 미확정 | 공식 슬라이드에 의무 문구 없음 | 운영진 확인 |
| 우수 프로젝트가 경상북도 저장소로 이관 | 확인 | 공식 슬라이드 11 | 선정·소유권·운영 조건 |

## 운영 질문

- [ ] 경상북도 외 전국 공공데이터도 지역 문제에 적용하면 인정되는가?
- [ ] 공공기관 외 공개 데이터는 보조 데이터로 사용할 수 있는가?
- [ ] Microsoft·Azure 기술 사용이 필수이거나 가산점 대상인가?
- [ ] 인프라와 서비스 결합형은 각 항목에서 어떻게 평가되는가?
- [ ] 프로토타입 보너스 10%는 기본 총점 100점에 추가되는가?

- [ ] 우수 프로젝트의 경상북도 저장소 이관 시 코드 소유권과 운영 책임은 어떻게 되는가?
