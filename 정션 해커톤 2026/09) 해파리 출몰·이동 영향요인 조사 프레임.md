# 해파리 출몰·이동 영향요인 조사 프레임

> [!summary] 팀 피드백 반영
> 조사 중심을 `어디에 해파리가 관측됐는가`에서 **`무엇이 해파리의 출몰과 이동을 바꾸는가`**로 전환한다. 다만 출몰과 이동은 서로 다른 과정이며 종별 생태도 다르므로, 하나의 범용 해파리 모델을 만들지 않는다. 3일 MVP는 공개 물리데이터와 가장 잘 맞는 **노무라입깃해파리의 이동 영향요인·민감도 시뮬레이터**를 우선한다.

## 1. 팀원 의견을 정확히 번역하면

팀 의견:

> 우리가 활용 가능한 데이터는 해파리가 관측되었느냐, 얼마나 관측되었느냐가 아니라 해파리 출몰에 무엇이 영향을 미치는지, 이동경로에 무엇이 영향을 미치는지에 맞춰 조사해야 한다. 해파리 관측 데이터는 없다.

검증 후 수정된 표현:

> 공공데이터에는 주간 모니터링 출현 여부·출현지점, 2019 출현보고, 2023 트롤조사가 존재한다. 그러나 **최신·연속·동일 개체 추적 자료와 충분한 발생 라벨은 없다.** 따라서 이를 실시간 위치나 이동 궤적으로 쓰지 않고, 출몰 조건과 이동을 만드는 환경요인을 중심으로 조사한다.

근거:

- [NIFS 해파리정보 API](https://www.data.go.kr/data/15157290/openapi.do)는 공식 설명상 정기 모니터링의 출현 여부·출현지점을 주간 집계한다. 아직 실제 최신 응답의 경북 행과 공간 형식은 확인하지 못했다.
- [과거 출현보고](https://www.data.go.kr/data/15147963/fileData.do)는 보고일자·위경도·크기·밀집여부 36,826행이지만 2019년 1회성 신고 자료다.
- [트롤조사](https://www.data.go.kr/data/15147957/fileData.do)는 종·개체수·개체/㎥가 있지만 375행의 2023년 1회성 자료다.

따라서 관측자료는 `실시간 시작점`이 아니라 다음 역할로 격하한다.

1. 연구 가설이 현실과 완전히 어긋나지 않는지 보는 약한 기준선
2. 모델 결과의 사후 공간·계절 대조
3. 관측 공백과 모델 불확실성을 드러내는 데이터

## 2. 먼저 분리해야 할 세 과정

```text
발생·증식                 운반·집적                  관측
polyp → ephyra → medusa   해류·바람·조석·행동       조사선·신고·가시성
        │                         │                       │
        └──────── 실제 출몰 ─────┴──────── 관측된 출몰 ───┘
```

### 2.1 발생·증식

폴립의 증식, 유생 방출, 성장과 생존을 바꾸는 생물·화학 과정이다. 수온·먹이·염분·부착기질 등의 영향을 받지만 종마다 방향과 임계값이 다르다.

### 2.2 운반·집적

이미 존재하는 개체가 해류·바람·조석·파랑과 자체 행동에 의해 이동하거나 특정 해역에 모이는 과정이다. `발생량`과 `도착 경로`를 혼동하면 안 된다.

### 2.3 관측

실제 개체가 있어도 조사 항로·수심·날씨·신고자 분포에 따라 보이거나 누락된다. 관측량은 생물량과 동일하지 않다.

## 3. 종을 분리해야 하는 이유

### 3.1 노무라입깃해파리 — 이동 중심 MVP에 적합

연구에서 한국 연안의 연도별 출현 강도는 중국 연안의 초기 분포와 황해·동중국해의 지균류·에크만류 결합에 크게 좌우됐다. 초기 분포를 바꾼 민감도 실험에서는 한국 연안 출현이 최대 3배 차이 났다. 또 다른 수치실험에서는 2008·2009년 집적 차이에서 수온보다 해류 영향이 더 컸다.

따라서 MVP 질문은 다음이다.

> **같은 가상 초기 분포에서 해류장·바람·방출시점이 달라지면 경북 방향 이동 가능 경로가 얼마나 달라지는가?**

근거:

- [Physical forces determine the annual bloom intensity of the giant jellyfish off Korea](https://www.sciencedirect.com/science/article/pii/S2352485517302980)
- [Giant jellyfish gathering in the Yellow Sea — numerical study](https://www.sciencedirect.com/science/article/pii/S0924796314003315)

### 3.2 보름달물해파리 — 발생 생태 연구에 적합하지만 공개데이터 공백이 큼

실험 연구에서는 폴립의 무성생식이 수온과 먹이 공급에 반응했고, 수온·염분·먹이의 효과와 상호작용이 종·서식지에 따라 달랐다. 인공·자연 부착기질과 저서생태계도 폴립 군집 발달에 영향을 준다.

하지만 경북 폴립 분포, 부착기질, 유생 방출, 먹이생물 자료가 없으므로 3일 안에 `발생 원인 예측`을 주장하기 어렵다.

근거:

- [수온·먹이와 Aurelia 폴립 증식 실험](https://www.jstage.jst.go.jp/article/pbr/5/3/5_3_98/_article)
- [수온·염분과 Aurelia 폴립 증식 실험](https://www.sciencedirect.com/science/article/pii/S0022098107004467)
- [저서생태계와 Aurelia 폴립 군집 현장 연구](https://www.sciencedirect.com/science/article/pii/S0025326X23006653)

### 4.2 이동·집적 요인

| 요인 | 작동 경로 | 공개데이터 | 우선도·주의 |
|---|---|---|---|
| 3차원 해류 | 수평 이류와 수심별 경로 | ROMS는 현재 공개 명세상 표층 유향·유속 | 1순위. 표층만으로 개체 이동 단정 금지 |
| 바람 응력·에크만 수송 | 표층과 상층 수괴 이동 방향 변경 | 해양수질 선박 풍향·풍속, 기상자료 | 노무라 한국 연안 분포 연구에서 핵심 |
| 조석·조류 | 연안 진입·전선·수렴대 형성 | 조류예보·조석관측·수치조류도 | 연안 집적에 중요 |
| 파랑·스토크스 표류 | 표층 이동과 해안 접근 수정 | 파고·주기·파향 | 파랑만으로 직접 변환하면 과장 |
| 수온·수괴 | 방출·생존·수직 위치와 수괴 경계 | ROMS·15분 수온 | 경로의 트리거·제약 조건 |
| 수심·해안선 | 장벽·연안 보유·좌초 | 수심도·해안선 | 필수 정적 피처 |
| 수직 이동 | 서로 다른 수심의 해류를 선택 | 공개된 종별 추적자료 없음 | 가장 큰 모델 불확실성 |
| 자체 유영 | 흐름을 따르거나 거슬러 이동 | 공개 실측 없음 | 해파리를 수동 입자로 동일시 금지 |
| 생활사·크기 | 유영능력·사망률·수심 선호 변화 | 종 기준표는 제한적 | 단계별 파라미터 필요 |

실제 태깅 연구는 해파리가 해류와 함께뿐 아니라 반대 방향으로도 움직일 수 있음을 보였다. 따라서 ROMS 입자는 **해파리 궤적이 아니라 물리적 운반 시나리오**다. [개체 태깅·해류 동시 추적 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC10485037/)

| 클로로필A·영양염·DO | 출현 예측 피처 | 생태 가설용 프록시; 인과 주장 금지 |
| 수심·해안선 | 시설 지도 | 물리 경계조건 |

> [!warning] 이중계산 주의
> ROMS가 이미 바람·조석 등의 강제력을 포함했다면 같은 변수를 단순 가산하면 이중계산이다. MVP에서는 `ROMS 기본 시나리오`와 `대체 해류장·방출시점·수직행동 가정`을 비교하고, 별도 바람 벡터는 설명 또는 민감도 변수로만 사용한다. 모델 메타데이터를 확인하기 전에는 합성 속도장이라고 부르지 않는다.

## 6. 새 제품 가설

### [가설] JellyFactor Lab / DriftLens

> **해파리 위치를 맞히는 서비스가 아니라, 어떤 환경요인과 가정이 이동 가능 경로를 얼마나 바꾸는지 보여주는 설명·반증 가능한 시뮬레이터**

직접 사용자 후보:

- 해양환경·수산 연구자
- 경북 연안시설 외부환경 담당자
- 공공데이터를 이용해 해양 이동 모델을 만드는 개발자

바뀌는 결정:

- 어떤 변수를 반드시 모니터링해야 하는가?
- 어떤 해역·수심·시점에 추가 관측을 배치해야 하는가?
- 어떤 가정이 바뀌면 경북 접근 시나리오가 무너지는가?
- 시설 운영자가 어떤 모델 결과를 신뢰하지 말아야 하는가?

출력:

1. **요인 카드:** 해류·방출시점·수온 조건·수직행동 가정의 근거와 데이터 신선도
2. **경로 앙상블:** 하나의 예측선이 아닌 가정별 물리 운반 경로
3. **민감도 순위:** 각 요인을 제거·교체했을 때 경로와 경북 접근 면적이 얼마나 변하는지
4. **반증 카드:** 모델이 성립하려면 확인해야 할 관측과 현재 빠진 데이터
5. **시설 교차:** 시나리오가 공개된 거친 시설 인접해역과 겹치는지 표시

## 7. 3일 MVP — 노무라입깃해파리 한 종

### Day 1 — 과학 가설과 데이터 생존성

- 문헌에 근거한 황해·동중국해 가상 source box와 방출시점 후보를 정의한다.
- ROMS 경계·유효시각·수온·유향·유속 응답을 확인한다.
- 조류·조석·파랑·풍향·풍속의 경북·동해 커버리지를 확인한다.
- `발생 원인`, `이동`, `관측 편향` 변수를 서로 다른 테이블에 저장한다.

### Day 2 — 물리 운반 앙상블

- 같은 가상 source에서 방출일·입자 깊이 가정·확산계수를 바꿔 앙상블을 실행한다.
- ROMS 기본 경로와 대체 가정을 비교한다.
- 해안 도착시각을 확정하지 않고 `경북 해역과 겹치는 시나리오 비율`을 계산한다.
- 각 결과에 `실제 관측 아님`, `동일 개체 추적 아님`, `생물행동 미포함/가정값`을 붙인다.

### Day 3 — 영향요인 설명과 반증

- leave-one-factor-out 또는 시나리오 비교로 요인 민감도를 계산한다.
- `해류장 교체`, `방출시점 ±7일`, `수직행동 가정`, `확산계수` 변화가 경로에 미치는 차이를 보여준다.
- 과거 NIFS 주간 분포와 겹침을 약한 sanity check로 표시한다.
- 기존 [[08) 해파리 간접 활용 아이디에이션과 CBL 선택지|JellyChaos]]에는 확정 위험이 아니라 `외부환경 시나리오`로 전달한다.

측정 가능한 지표:

- API 생존율, 시·공간 커버리지, 결측률
- 요인·가정별 경로 분산과 경북 해역 중첩 비율 변화
- 모든 결과의 데이터·문헌 근거 추적률 100%
- NIFS 과거 분포와의 공간 겹침 또는 거리 — 단, 정확도나 개체 추적으로 부르지 않음

측정 불가능한 지표:

- 실제 해파리 개체의 도착 ETA
- 특정 요인이 실제 출몰을 몇 % 증가시켰다는 인과효과
- 관측이 없는 시점의 실제 개체수
- 보름달물해파리 폴립 발생량

## 8. 이 방향의 kill switch

1. ROMS 응답이 경북·동중국해 경로를 연결할 공간범위나 과거장을 제공하지 않는다.
2. source box와 방출시점을 문헌만으로도 방어할 수 없다.
3. 수직 유속·수심별 해류가 없어 민감도 범위조차 정직하게 표현할 수 없다.
4. 주최 측이 시뮬레이션보다 현재 경북의 직접 사용·측정 가능한 효과를 강하게 요구해 연구 도구의 공공가치가 약해진다.

위 조건이 발생하면 이동경로를 그리지 않고 `영향요인 Evidence Graph + 데이터 공백·추가 관측 설계 도구`로 축소한다.

## 9. CBL Gate 변경

- 이전 선도 가설: 해파리 이벤트를 시설 확인·훈련 작업으로 변환
- 팀 피드백 후 선도 가설: 해파리 출몰·이동을 바꾸는 요인을 설명하고 가정별 경로 차이를 시험
- 현재 단계: **Engage — Iterate 유지**
- 이유: 팀 피드백이 Challenge의 초점을 바꾸었고, 직접 사용자와 실제 결정은 아직 검증하지 않았다.
- Investigate 진입 전 필요한 팀 결정:
  1. 노무라입깃해파리 한 종에 동의하는가?
  2. 핵심 결과를 `경로 예측`이 아니라 `요인 민감도·가정 비교`로 정의하는가?
  3. 1차 사용자를 연구자와 시설 운영자 중 누구로 둘 것인가?
