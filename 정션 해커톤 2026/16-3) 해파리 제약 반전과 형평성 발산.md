# 해파리 제약 반전과 형평성 발산

> [!abstract] 방법
> 정상 상황·대형 시설·풍부한 데이터·항상 연결된 화면이라는 암묵적 조건을 하나씩 뒤집었다. 제품 결정을 위한 우선순위가 아니라 누락된 설계 공간을 찾기 위한 발산이다.

## 1. 제약 반전 카드

| 통상 가정 | 반전 | 새로 보이는 후보 |
| --- | --- | --- |
| 관측이 있어야 판단 | 관측이 없다는 사실이 핵심 신호 | 관측 커버리지 원장, 다음 조사위치 추천 |
| 인터넷과 API가 정상 | 현장에서 모두 끊김 | 마지막 유효시각·오프라인 근거팩·지연 경보 |
| 모델 하나가 최선 | 모델들이 서로 충돌 | 불일치 지도·사람 검토 큐 |
| 위험이 높을 때만 행동 | 불확실성이 높을 때 확인 | 정보이득 기반 샘플링 |
| 대형 시설이 사용자 | 1인 어선·소규모 양식장이 사용자 | SMS/음성·항로 단위·공동 자원 |
| 전문용어가 통함 | 종명·확률을 이해하지 못함 | 근거와 행동을 분리한 평문·그림 |
| 양성 신고가 유용 | `없음` 신고가 더 희소 | 음성 관측 보상·경로완주 미션 |
| 한 국가 데이터면 충분 | 공급원·수송이 국경을 넘음 | 다국어·출처계보·국경간 사건 규격 |
| 출현 전 경보가 가치 | 경보 후 해제 판단이 더 어렵다 | 종료 근거·재평가 타이머 |
| 정확도 경쟁 | 틀렸을 때 설명·복구가 핵심 | 예측 버전·근거·수정 이력 |
| 자동화가 목표 | 사람 승인이 법·안전상 필수 | 승인대기·대리승인·에스컬레이션 |
| 데이터 공개가 선 | 시설 세부는 보안정보 | 로컬 계산·요약증명·선택적 공개 |
| 제거하면 끝 | 수거물이 새 폐기물 사건 | 품질검사·인계·처리 추적 |
| 해파리는 피해 | 관측 가능한 이동체 | 해류모델·센서 품질 검증용 생물 드리프터 |
| 해파리만 다룸 | 살파·해조류와 절대 섞지 않음 | 종별 causal firewall와 플러그인 계약 |
| 경보 수신자가 행동 | 자원이 없어 행동 불가 | 선박·그물·전문가 상호지원 |

## 3. 형평성 질문

- 누가 해파리 관측 노동을 무급으로 제공하고, 누가 상업적 이득을 얻는가?
- 대형 시설이 센서를 독점하면 인근 어업인·양식장이 같은 위험을 더 늦게 알게 되는가?
- 오탐 비용을 어업인·관광업자에게 떠넘기면서 모델 운영자는 정확도만 높였다고 말할 수 있는가?
- 경보에서 배제된 도서·야간·저연결 지역을 `데이터 없음`으로 처리하면 위험이 사라진 것처럼 보이지 않는가?
- 시민 사진의 위치·시간이 노동·사생활·어장 비밀을 노출하는가?
- 시설보호를 위한 제거·차단이 비표적 생물과 소규모 어업에 어떤 비용을 전가하는가?
- 보험·규제에서 모델 점수가 사용될 때 설명·이의제기·정정권이 있는가?
- 국경 밖 공급원 지역의 데이터 제공자에게 혜택이 돌아가는가?

### 3.1 배제·부담 시나리오 20개

1. 시민·어업인이 무급으로 만든 관측 데이터의 이익이 대형 시설에만 돌아간다.
2. 어업인의 정확한 신고좌표가 어장 비밀과 노동경로를 노출한다.
3. 오탐 경보로 소형 어선만 출항을 포기하고 대형 선사는 손실을 흡수한다.
4. 도서지역은 관측이 적다는 이유로 `안전`하게 표시되어 현장확인에서 배제된다.
5. API 장애 때 오프라인 사용자는 마지막 정보의 만료 여부를 알지 못한다.
6. 색상만 사용하는 위험지도에서 색각 이상 사용자가 단계를 구분하지 못한다.
7. 한국어 전용 경보로 외국인 선원이 같은 위험을 늦게 알게 된다.
8. 지도 전용 인터페이스가 시각장애 관광객의 독립적 판단을 막는다.
9. 음성 전용 경보가 청각장애 안전요원에게 전달되지 않는다.
10. 스마트폰 앱만 지원해 고령 어업인과 저연결 사용자가 신고·수신에서 빠진다.
11. 센서가 많은 대형 시설 주변만 모델 성능이 좋아져 공공 조사자원이 다시 집중된다.
12. 설명·이의제기 없이 모델 점수가 보험료·보장 제외에 사용된다.
13. 시설보호를 위한 제거·차단이 비표적 생물을 죽이지만 비용은 공공이 부담한다.
14. 외곽망이 해양물질을 인접 해안·소규모 시설 쪽으로 우회시킨다.
15. 야간 경보가 발령돼도 교대인력이 없는 소규모 조직은 행동할 수 없다.
16. 투명성 요구로 중요 취수구 위치·운영세부가 과도하게 공개된다.
17. 공식 발표 전 내부정보에 접근 가능한 기관·기업만 먼저 대비한다.
18. 전문가 검증 부족을 시민 자원봉사자의 무급 노동으로 메운다.
19. 상호지원 자원배분이 경제가치가 큰 시설을 먼저 보호하고 어촌을 뒤로 미룬다.
20. 수거·퇴비화·폐기 과정의 악취·오염 부담이 처리시설 인근 주민에게 집중된다.

## 4. 제약을 반영한 제품 씨앗 20개

1. 오프라인 우선 해양 사건 브리핑
2. 음성 기반 어선 항로 위험 읽기
3. 음성 관측을 보상하는 시민과학 패스
4. 다국어·아이콘 기반 종 불명 신고
5. 색 외 패턴을 쓰는 접근성 위험지도
6. 모델 이의제기·정정 요청 창구
7. 시설 데이터는 로컬에 두는 연합 검증
8. 공개 근거와 비공개 운영값을 분리한 이중원장
9. 위험노출 대비 관측공백 형평성 지도
10. 소규모 사업자 공동 센서·조사 협동조합 소프트웨어
11. 시민 관측 기여도와 데이터 재사용 추적
12. 오탐·미탐 비용을 이해관계자별로 보여주는 시뮬레이터
13. 경보 해제 근거를 요구하는 만료형 알림
14. 야간·도서 우선 현장확인 배정
15. 어장 비밀을 보호하는 좌표 흐림·지연 공개
16. 비표적 생물 영향까지 남기는 차단조치 감사
17. 국경간 데이터 계보와 번역 레이어
18. 연구자용 실패·음성 라벨 데이터 카탈로그
19. 주민용 사건 정정 타임라인
20. 예측이 아니라 `지금 모르는 것`을 읽어주는 불확실성 브리핑
