# 해파리 원거리 시스템 유추와 패턴 이식

> [!abstract] M4 결과
> 해파리를 다른 위험의 이름으로 바꾸는 은유가 아니라, `불완전 관측 → 이동·확산 → 반복 갱신 → 비용 있는 확인 → 사람 플레이북 → 사후라벨`이라는 구조를 공유하는 12개 시스템을 비교했다. 아래 30개 씨앗은 **동등한 팀 검토 재료**이며 순위·점수·추천이 아니다.

계획: [[11) 해파리 Investigate 발산 조사 계획]] · 마인드맵: [[12) 해파리 무한 연상 마인드맵.canvas]]

## 1. 구조적 유추 판정 기준

다음 8개 중 5개 이상이 제품 흐름에 실제로 대응할 때 구조적 유추로 본다.

1. 위험이 직접 보이지 않거나 관측이 불완전하다.
2. 시간·공간상 이동하거나 확산한다.
3. 여러 불완전한 센서·신고·모델을 합친다.
4. 예측에 불확실성이 있고 반복 갱신된다.
5. 확인 행동에 비용이 든다.
6. 가능성뿐 아니라 영향 결과도 함께 평가한다.
7. 역할·임계값·플레이북에 따라 사람이 대응한다.
8. 결과가 늦게 확인돼 사후라벨과 백테스트가 필요하다.

`해파리용 레이더`, `해양 백신`, `바다의 안티바이러스`처럼 이름만 빌리면 구조적 유추가 아니라 은유다.

## 3. 반복된 원형 패턴

```text
센티널
→ 다중 관측·모델과 불확실성
→ 가능성과 결과의 분리
→ 사람 검증 태스크
→ 역할별 플레이북
→ 기관 간 자원 요청·상호지원
→ 현장 결과·오탐·미확인 사후라벨
→ 모델·절차 갱신
```

이 흐름은 제품 권고가 아니라 여러 외부 시스템에서 반복된 구조다. 해양현장에 같은 역할·센서·라벨이 실제 존재하는지는 별도 검증한다.

## 5. 이식하면 안 되는 연결

- 해파리를 유류·부표처럼 완전한 수동 추적자로 간주하지 않는다.
- 해파리를 오염·저산소·AMR의 진단값으로 쓰지 않는다.
- 출현률을 절대 개체밀도로 쓰지 않는다.
- 해외 원전 정지 사례를 경북 발생 사실로 바꾸지 않는다.
- 사이버 자동대응을 해양·원전·재난에 그대로 복제하지 않는다.
- 준비도 점수를 실제 안전성과 동일시하지 않는다.
