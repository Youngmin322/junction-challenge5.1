# 해파리 Investigate 발산 조사 계획

> [!abstract] 목적
> 기존 `Blue Canary` 수렴안을 증명하려 하지 않고, 팀이 선택할 문제공간을 넓힌다. 해파리를 생물·데이터·물질·사건·은유·시장·조직 신호로 각각 다시 보고, 각 연결의 근거·반례·미지·트레이드오프를 팀이 비교할 수 있게 만든다. **이번 작업은 순위·추천·결정을 내리지 않는다.**

관련 문서: [[10) Punchline 기반 해양환경 신호 아이디에이션]] · [[09) 해파리 출몰·이동 영향요인 조사 프레임]] · [[08) 해파리 간접 활용 아이디에이션과 CBL 선택지]]

## 1. 조사 원칙

1. `해파리가 늘었다`, `기후변화가 해파리를 만들었다`, `공개데이터로 실제 개체를 예측한다`를 출발 가정으로 두지 않는다.
2. 종·생활사·발생·성장·운반·관측·피해를 분리한다.
3. 사실, 산업계 주장, 연구 결과, 유추, 제품 가설을 다른 라벨로 기록한다.
4. 직접 경고·어업·해수욕장 안전에 갇히지 않되, 참신함만 있고 사용자 결정이 없는 아이디어는 따로 표시한다.
5. 각 방법은 다른 방법의 상위안을 보지 않고 먼저 발산한 뒤 마지막에만 교차한다.
6. 사용자가 자는 동안 외부 발송·계정 생성·유료 결제·기관 접촉은 하지 않는다.
7. 각 방법은 생성 단계에서 09)·10)의 제품명과 설계 원칙 어휘를 사용하지 않는다. 기존 결과와의 매핑은 생성이 끝난 뒤에만 수행한다.
8. 모든 산출물에 공통 라벨 `확인 사실 / 실험 / 관측 상관 / 수치모델 / 공식·규제 / 산업 경험 / 상업 주장 / 구조적 유추 / 은유 / 미확인`을 사용한다.
9. 직전 20개 산출에서 새 의미범주가 0개면 해당 방법은 포화로 종료한다. 새 범주가 나오면 개수 목표를 넘겨도 계속한다.
10. 조사 결과가 핵심 전제를 반증하거나 합법·안전·데이터 제약 때문에 실행 불가능하면 Stop도 정상 결과로 기록한다.

## 2. 실행할 여덟 가지 방법

### M1. 무한 연상 마인드맵 — 의미 공간 확장

**질문:** `해파리`에서 몇 단계 떨어진 곳까지 문제·데이터·기술·행동을 확장할 수 있는가?

- 1차 가지: 생물학, 물리, 물질, 감각, 위험, 산업, 데이터, 문화, 은유, 제도에 더해 초국경, 타 분류군, 건강, 시장, 에너지, 수산경제, 역사, 통계, 형평성
- 2차 가지: 생활사·형태·행동·성분·이동·집적·관측·피해·회수·가공·상징
- 3차 가지: 사용자, 바뀌는 결정, 결합 데이터, 소프트웨어 패턴
- 결과물: `12) 해파리 무한 연상 마인드맵.canvas`와 해설 노트
- 생성 단계에서 기존 제품명·운영 패턴을 넣지 않고 분기별로 다른 질문을 사용한다.
- 종료조건: 200개 이상 개념 노드, 18개 이상 대분기, 직전 20개에서 새 범주 0개

### M2. 원거리 키워드 카드소팅 — 강제 연결

**질문:** 해파리와 무관해 보이는 산업·기술·사회 키워드를 붙였을 때 어떤 새로운 사용자 결정이 생기는가?

- 카드 덱: 사이버보안, 금융, 큐잉, 음악, 패션, 게임, 법의학, 교육, 물류, 반도체, 도시계획, 우주, 보험, 조직행동, 접근성 등
- 조합법: `해파리 속성 카드 × 원거리 분야 카드 × 소프트웨어 패턴 카드 × 결정 카드`
- 1차 발산 후 `물리적 연결 / 구조적 유추 / 은유만 있음 / 기각` 네 묶음으로 소팅
- 결과물: `13) 해파리 원거리 키워드 카드소팅.md`
- 종료조건: 원거리 카드 40개 이상, 조합 60개 이상, 기각 사유 포함 상위 20개

### M3. 원인 사다리와 Evidence Landscape — “왜 출몰하는가” 조사

**질문:** 과학 문헌·공공기관·산업계 보고서는 해파리 출몰과 피해 원인을 어떻게 다르게 설명하는가?

- 과정: 폴립 정착 → 증식 → 에피라 방출 → 성장·생존 → 운반·집적 → 관측 → 사회·산업 피해
- 원인축: 수온, 염분, 먹이, 저산소, 성층, 인공기질, 어획, 수괴·해류, 바람, 초기분포, 관측노력. 기존 목록에 없는 원인축이 출처에 등장하면 신규 축으로 보존한다.
- 출처축: 체계적 검토·실험·수치모델·공공기관·발전/담수화/해운 산업 보고서
- 각 주장에 공통 증거라벨과 `이해상충: 규제·공공 / 학술 / 비영리 / 상업 / 불명`을 함께 부여
- 결과물: `14) 해파리 출몰 원인과 산업계 리포트 조사.md`
- 종료조건: 25개 이상 1차·공식·산업 출처, 주장-근거 매트릭스, 반증된 통념 목록

### M4. 원거리 시스템 유추 — 다른 산업의 해결 패턴 이식

**질문:** 직접 보이지 않고, 이동하며, 늦게 확인되고, 대응 비용이 큰 위험을 다른 분야는 어떻게 다루는가?

- 비교 영역은 `불완전 관측·이동·늦은 확인·대응비용`이라는 제약만으로 찾고, 기존 제품 목록을 보지 않는다.
- 패턴 이름은 비교 시스템의 공식 원문 용어로 먼저 기록하고, 기존 제품 어휘로 번역하지 않는다.
- 결과물: `15) 해파리 원거리 시스템 유추와 패턴 이식.md`
- 종료조건: 8개 이상 비교 시스템, 패턴 20개 이상, 해파리 적용 제품 20개 이상

### M5. 이해관계자·가치사슬·Negative Space — 하지 않는 일 찾기

**질문:** 해파리 사건 전·중·후에 누가 어떤 결정을 내리며, 현재 데이터가 답하지 못하는 질문은 무엇인가?

- 행위자: 연구자, 조사선, 지자체, 시설 운영·정비, 항만, 선사, 양식, 보험, 조달, 언론, 시민, 데이터 개발자
- 시간축: 평시 준비 → 조건 변화 → 관측 → 확인 → 대응 → 회수 → 사후학습 → 예산·설계
- Negative Space는 이해관계자의 실제 결정·회피·수작업·미충족 질문에서 귀납적으로 도출하며 사전 예시를 두지 않는다.
- 결과물: `16) 해파리 이해관계자 가치사슬과 미충족 결정.md`
- 종료조건: 이해관계자 12개 이상, 결정 50개 이상, 미충족 JTBD 20개 이상

### M6. Kill-the-Leader / Pre-mortem — 기존 전제 반증

**질문:** 기존 `Blue Canary`, 시설운영, 관측배차, 자원화 등 눈에 띄는 후보가 실패했다면 무엇 때문인가?

- 각 기존 후보에 대해 실패원인, 반대증거, 더 단순한 대안, 데이터 부재, 채택장벽을 작성
- 기존 후보를 전혀 사용하지 않는 대체 문제공간을 최소 20개 생성
- 결과물: `16-1) 해파리 기존 전제 반증과 대체 문제공간.md`
- 종료조건: 기존 후보군별 kill 조건, 반대증거 20건 이상, 대체 문제공간 20개 이상

### M7. 기존 대안·경쟁·산업 솔루션 스캔

**질문:** 연구기관·공공기관·산업은 지금 무엇으로 해파리를 관측·예측·차단·수거·활용·소통하고 있으며 무엇을 해결하지 못하는가?

- 범주: NIFS·JEDI·시민과학, 입자추적, 취수구 차단망·스크린·센서, 담수화 전처리, 수거·자원화, 피해·특보·SOP
- 결과물: `16-2) 해파리 기존 대안과 산업 솔루션 스캔.md`
- 종료조건: 기존 대안 30개 이상, 운영주체·입력·출력·한계·미충족 질문 기록

### M8. 제약 반전·극단 사용자·형평성 렌즈

**질문:** 공공데이터·예산·실시간 센서·전문가·인터넷이 없거나, 1인 조직·무인시설·국외 발생원처럼 극단적인 조건에서는 어떤 문제가 남는가?

- 제약 반전: 공공데이터 0개, API 중단, 관측 0건, 예산 0원, 시설 내부데이터 없음
- 극단 사용자: 1인 어촌계, 무인 관측소, 야간 교대자, 외국인 선원, 색각·디지털 접근성이 낮은 사용자
- 형평성: 데이터 생산자와 수혜자·부담자가 다른 경우, 오탐 비용이 특정 집단에 집중되는 경우
- 결과물: `16-3) 해파리 제약 반전과 형평성 발산.md`
- 종료조건: 제약 10개, 극단 사용자 10개, 배제·부담 시나리오 20개 이상

## 3. 교차 색인과 팀 의사결정 재료 구성

여덟 방법의 결과를 수렴·점수화하지 않고 다음 기준으로 교차 색인한다. 같은 아이디어가 여러 방법에서 나와도 우위의 증거로 단정하지 않고 `반복 발견` 메타데이터만 남긴다.

| 기준 | 질문 |
|---|---|
| 반복 발견 | 서로 다른 방법 2개 이상에서 독립적으로 나온 문제인가? |
| 근거 강도 | 1차·공식 근거가 있는가, 유추나 은유뿐인가? |
| 사용자 결정 | 누가 무엇을 다르게 결정하는가? |
| 공공데이터 핵심성 | 데이터가 화면 장식이 아니라 판단을 바꾸는가? |
| 3일 실증 | `데이터→판단→행동→기록` 한 흐름이 가능한가? |
| 경북성 | 경북의 연안·산업·행정 맥락에서 구체화 가능한가? |
| 반증 가능성 | 무엇이 틀리면 후보를 버릴지 말할 수 있는가? |

최종 결과물은 `17) 해파리 Investigate 발산 아틀라스와 결정 재료.md`로 만든다. 추천 순위나 단일 결론을 만들지 않고 다음 네 묶음을 모두 보존한다.

1. 현재 공개근거와 데이터로 탐색 가능한 후보
2. 데이터·기관 제휴가 있어야 검증 가능한 후보
3. 연구 질문으로 가치가 있지만 제품 판단은 이른 후보
4. 구조적 연결 없이 은유만 있거나 근거가 반증된 후보

각 묶음은 `선택 권고`가 아니라 검토 조건이다. 팀이 어떤 가치와 제약을 우선할지 정하기 전에는 후보 간 우열을 매기지 않는다.

## 5. CBL 위치

- 단계: **Investigate를 위한 책상조사·발산**
- 현재 판정: **Iterate — 책상조사·발산은 완료 단계, 사람·API 실물 검증은 미통과**
- 팀의 Punchline과 기존 `Blue Canary`는 비교 대상이지 정답이 아니다.
- 최종 Challenge와 제품 선택은 팀만 결정한다. 이번 조사 결과물은 선택을 위한 재료이며 권고안이 아니다.
- 사용자·현장·전문가 인터뷰는 이번 무승인 야간 조사 범위에 없으므로 `사람 증거 0건`을 명시한다. 책상조사 완료가 Investigate Gate 통과를 뜻하지 않는다.
- Stop도 팀이 채택할 수 있는 정상 선택지다. 특히 `경북 문제 규모가 매우 작음`, `현재 대안으로 충분함`, `소프트웨어보다 물리 설비가 지배적임`, `필요 라벨을 합법·현실적으로 확보할 수 없음`이 확인되면 해당 문제공간을 중단할 근거가 된다.
