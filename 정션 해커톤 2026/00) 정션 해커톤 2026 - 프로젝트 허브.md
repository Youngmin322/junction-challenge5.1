## 지금 확인된 핵심

1. AI:GO의 에이전트 스쿼드 기능을 핵심 기반으로 사용한다.
2. 수학·코딩을 포함한 여러 범주의 문제를 해결할 수 있는 스쿼드를 설계한다.
3. 에이전트별 역할, 모델, 도구, 검증·수정·중단 방식을 설계한다.
4. 평가 배점은 벤치마크 40점, 과정 시각화 30점, 토큰 효율성 30점이다.
5. 세부 문제 주제와 제품 방향은 아직 확정하지 않는다.

## 현장에서 우선 확인할 항목

- [x] 성능·시각화·토큰 효율성의 정확한 배점 — 40/30/30
- [ ] 벤치마크 문제의 범주와 입출력 형식
- [ ] 평가 문항 또는 테스트 케이스의 공개 범위
- [x] 제출 파일의 상위 형식 — Squad Template JSON 1개 + 트랙별 one-shot prompt 1개
- [ ] Squad Template JSON의 정확한 스키마와 필수 필드
- [x] 제출 Queue 제한 — 동시 실행 1개, 대기 3개
- [x] 인터랙티브 시각화의 필수 여부 — PDF 기준 필수 결과물
- [ ] 시각화 제출 형식과 인정 범위
- [ ] 외부 도구 및 로컬 코드 실행 허용 범위
