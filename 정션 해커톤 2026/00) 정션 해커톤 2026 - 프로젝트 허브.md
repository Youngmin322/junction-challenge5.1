# 정션 해커톤 2026

## 현재 상태

- 선택 트랙: Microsoft Korea × 경상북도 — **공공데이터를 활용한 경상북도 지역 문제 해결**
- 팀 저장소: [junction-challenge5.1](https://github.com/Youngmin322/junction-challenge5.1)
- 트랙 방향: 공공데이터를 AI가 활용 가능한 형태로 가공하거나, 공공데이터와 AI로 경상북도의 실제 문제를 해결하는 서비스 개발
- 프로젝트 세부 주제: 공공데이터의 존재와 지역 수요를 함께 검증한 뒤 결정
- 기록 원칙: **확인된 사실**, **추측**, **미확정 사항**을 구분하여 누적

## 지금 확인된 핵심

1. 공공데이터를 최소 1개 이상 실제로 사용한다.
2. 데이터 인프라 구축과 지역 문제 해결 서비스 중 하나 이상을 선택할 수 있다.
3. 인프라 트랙은 GitHub 공개와 오픈소스 라이선스 명시가 필수다.
4. 단순 UI 목업이나 원본 데이터 노출이 아니라 실제 데이터 통합과 동작 가능한 프로토타입을 만든다.
5. 기본 평가에서 공공 가치·적용 가능성이 35%로 가장 높다.
6. 구체 주제는 경상북도 사용자 문제와 사용 가능한 공공데이터를 함께 확인한 뒤 결정한다.

## 현장에서 우선 확인할 항목

- [x] 최소 공공데이터 사용 조건 — 1개 이상
- [x] 접근 방식 — AI용 데이터 인프라 또는 지역 문제 해결 서비스, 결합 가능
- [x] 인프라 방식의 공개 조건 — GitHub와 오픈소스 라이선스
- [x] 평가 배점 — 기술 25, 공공 가치 35, 혁신 25, 지속 가능성 15
- [ ] 프로토타입 보너스 10%의 정확한 합산 방식
- [ ] 경상북도 외 전국 단위 데이터의 인정 범위
- [ ] Microsoft·Azure 기술 사용 의무 또는 가산점 여부
- [ ] 제출 형식, 배포 URL 요구, 최종 마감 시각
- [ ] 우수 프로젝트의 경상북도 저장소 이관 조건과 라이선스
