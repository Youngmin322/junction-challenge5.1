### 한글 파일명 문제 수정

- macOS 클론 직후 CBL 문서 10개가 `untracked`로 표시되는 문제 발견
- 원인: 한글 파일명의 Unicode 정규화 방식이 NFD와 NFC로 혼합됨
- 파일 본문을 바꾸지 않고 10개 경로를 NFC로 정규화
- 새 클론에서 비-NFC 경로 0개 및 깨끗한 작업 트리 확인
- 커밋: `5ba4112 한글 파일명 정규화`
- PR: [#1 한글 파일명 정규화](https://github.com/Youngmin322/junction-challenge5.1/pull/1)
- 결과: `main`에 병합 완료

### 트랙 정보 확인

- 접근 트랙을 Lablup × FuriosaAI의 “최고의 에이전트 스쿼드 구축”으로 확인
- 필수 또는 주요 결과물, 평가 요소, 토큰 효율성 설명 정리
- 발표 자동 전사에 오류가 많으므로 이미지와 공식 자료를 우선 근거로 사용하기로 함

### 용어 정정

- “미공개 문제”는 공식 표현이 아니라 해석이었음을 확인
- 이후에는 “주최 측이 제공하는 여러 범주의 자동 채점형 벤치마크 문제”로 기록
- 비공개 평가 문항이나 숨겨진 테스트 케이스의 존재 여부는 미확정으로 유지

### Lablup 제공 PDF·NotebookLM 조사

- 팀 NotebookLM에 업로드된 `3 LABL.pdf`만 근거로 챌린지 규칙을 질의
- 핵심 응답의 PDF 인용 세부정보와 화면 캡처 문구를 추가 질의로 재검증

- Squad Template JSON 1개와 트랙별 one-shot prompt 1개 제출을 확인
- 무료·무제한 Checking, 동시 실행 1개·대기 3개 Queue 제한을 확인
- PDF 기준 인터랙티브 시각화를 필수 결과물로 정리
- 벤치마크 입출력 스키마, 타임아웃·실패 규칙, 외부 도구 허용 범위, 시각화 제출 형식, 최종 마감은 미확정으로 유지
