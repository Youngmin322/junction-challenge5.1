# 해파리 데이터 조사와 제품 후보

> [!summary] 결론
> 팀이 발견한 [해파리종 정보](https://www.data.go.kr/data/15147938/fileData.do)는 현재 출현을 알려주는 데이터가 아니라 55종의 독성·증상·형태를 붙이는 **정적 기준표**다. 동적 제품의 중심은 2026년에 개방된 [국립수산과학원 해파리정보 OpenAPI](https://www.data.go.kr/data/15157290/openapi.do)와 [ROMS 표층 유향·유속·수온 예측](https://www.data.go.kr/data/15142227/openapi.do)이다. 현재 가장 유력한 제품은 `경북 동해안 해파리 도착시간·현장 행동 큐`다.

> [!warning] 검증 상태
> 포털 메타데이터, 공식 NIFS 게시판과 API 명세를 확인했다. 이 세션에는 NIFS·공공데이터포털 인증키가 없어 최신 API 원시행과 결측률까지 확인하지 못했다. 따라서 아래의 출현률·지점·예측 필드는 스키마상 확인 결과이며, 실제 경북 행 수와 최신 관측시각은 키 발급 직후 다시 측정해야 한다.

## 1. 조사 범위와 판단 기준

범위를 해파리 예측에만 제한하지 않고 다음을 함께 조사했다.

- 현재·과거 해파리 출현, 종, 밀집도와 관측 노력
- 수온·염분·해류·조류·파랑·조석·기상·적조
- 해수욕장·어업·양식장에 대한 노출과 피해 대리변수
- 신고, 모니터링, 특보, 구제·폴립 제거와 행동 이력
- 해파리 자원화 가능성과 공개데이터 공백

동적성은 다음 세 조건으로 판단했다.

1. 관측·보고·예측 시각이 있는가?
2. 같은 지역이나 대상을 반복 측정하는가?
3. 새 값이 경보·순찰·조업·해수욕장 운영·구제 같은 행동을 바꾸는가?

역할은 기존 프레임과 동일하게 표시한다.

| 역할 | 의미 |
| --- | --- |
| A | 문제 규모·노출·기준선 |
| B | AI가 현재 또는 미래 상태를 판단하는 동적 신호 |
| C | 사람이 실행할 조치·시설·운영 자원 |
| D | 조치 이후 효과를 측정하는 결과 |
| E | 좌표·격자·지역·종·시각을 연결하는 결합 기반 |

- 포털 등록·수정: 2025-08-28 / 2025-09-02
- 갱신: 수시라고 표시되지만 실제로는 1회성 데이터
- 규모: 55행
- 이용조건: 무료, 이용허락 제한 없음
- 역할: C / E
- 동적성: ✗ / ✗ / △

필드:

- 해파리명·영문명
- 크기
- 형태 및 특징
- 출현시기 및 분포
- 쏘임 증상

적절한 사용:

- 실시간 출현 종 코드에 독성·쏘임 증상을 붙이는 룩업
- 시민 신고 사진에서 추정된 종의 특징을 설명
- 같은 출현률이라도 독성이 높은 종의 위험점수를 올림
- 해수욕장·어업인 대상 행동 문구를 종별로 다르게 생성

부적절한 사용:

- 현재 위험지역 판정
- 출현량·밀집도·이동속도 계산
- 2025년 포털 등록일을 생태 관측 최신일로 해석

## 3. 최우선 직접 데이터

- 데이터: [공공데이터포털 15157290](https://www.data.go.kr/data/15157290/openapi.do)

- 최신 게시 확인: [NIFS 해파리속보](https://www.nifs.go.kr/board/actionBoard0022List.do)
	- 형식: LINK OpenAPI, JSON/XML
- 제공기관: 국립수산과학원
- 포털 등록·수정: 2026-01-22
- 승인: 개발 자동승인, 운영 심의
- 트래픽: 기관 정책에 따름
- 이용조건: 무료, 이용허락 제한 없음
- 실제 생산주기: 포털은 실시간으로 분류하지만 핵심 콘텐츠는 주간보고와 수시 특보
- 역할: A / B / C / D / E
- 동적성: ✓ / ✓ / ✓

제공 범위:

- 조사 시점별 출현 여부와 출현지점
- 해파리 출현률·출현빈도
- 종별 분포도와 수온
- 주간 변동
- 조치사항과 지자체·어업인 협조사항
- 금후 전망

대표 API 구조:

| 기능 | 식별자 | 용도 |
| --- | --- | --- |
| 목록 | `jellyList` | `sdate`, `edate` 기간의 속보·주간보고 목록 조회 |
| 속보 상세 | `jellyDetail` | 특보와 속보 상세 조회 |
| 주간보고 상세 | `jellyDetail2` | 지역·종별 출현률, 분포·전망·조치 조회 |

목록 호출 형식은 `https://www.nifs.go.kr/OpenAPI_json?id=jellyList&key={KEY}&sdate=YYYYMMDD&edate=YYYYMMDD`로 확인됐다.

경북 전용 핵심 필드:

- `nom_ratio_10`: 노무라입깃해파리 경북 출현률
- `bor_ratio_10`: 보름달물해파리 경북 출현률
- `etc_ratio_10`: 기타 해파리 경북 출현률

최신성 확인 결과:

- 공식 게시판에서 2026-08-20 주간보고 16회차까지 목록이 확인됐다.
- 2026-07-30에는 특보 주의보 상향과 예비주의보 확대가 별도로 게시됐다.
- 즉, 포털의 과거 1회성 파일과 달리 현재 운영되는 소스다.

중요한 해석 한계:

- 출현률은 해역 전체의 절대 개체밀도와 같지 않다. 모니터링 응답자 중 관측 비율일 가능성이 있으므로 조사자 수와 응답률을 함께 확인해야 한다.
- 주간 집계는 당일 해수욕장 통제를 직접 결정할 만큼 촘촘하지 않을 수 있다.
- 분포도가 이미지 경로인지 기계 판독 가능한 공간 객체인지 키 발급 후 확인해야 한다.
- 공식 주간보고 PDF는 게시물별 공공누리 제3유형일 수 있으므로, 변경·재배포보다 구조화 API 필드를 우선한다.

## 4. 해양환경 동적 데이터

### 4.1 ROMS 수치예측모델 — 가장 중요한 이동 피처

- 데이터: [국립해양조사원 ROMS 수치예측모델](https://www.data.go.kr/data/15142227/openapi.do)
- 형식: REST, JSON/XML
- 갱신: 실시간 표기
- 핵심 필드: 예측일·예측시간, 위도·경도, 표층 유향·유속·수온
- 지역 필터: 경북 동해안의 최소·최대 위경도 bounding box
- 이용조건: 공공누리 제1유형
- 역할: B / E
- 동적성: ✓ / ✓ / ✓

활용:

- 현재 출현 좌표에서 표층 흐름을 따라 6·12·24·48시간 후의 가능 위치 계산
- 포항·영덕·울진·울릉 해안 세그먼트별 도착 가능시간 산출
- 단일 선이 아니라 모델 오차를 반영한 확률 영역으로 표현

한계:

- 수치모델 예측이지 해파리 추적 관측이 아니다.
- 해파리는 종별 운동성, 수심, 바람, 파랑의 영향을 받으므로 표층 이류만으로 공식 도착시간을 단정하면 안 된다.

## 6. 데이터 결합 설계

### 표준 결합키

| 원천 | 원래 키 | 표준화 |
| --- | --- | --- |
| NIFS 해파리 | 출현지역·지점, 조사주차, 종 | `coast_segment_id`, `week`, `species_id` |
| 수온·염분 | 격자번호, 분석일자 | 격자 중심 WGS84와 UTC/KST 시각 |
| ROMS | 위경도, 예측기준·유효시각 | `lon`, `lat`, `issued_at`, `valid_at` |
| KHOA 관측 | 관측소코드, 관측일시 | 관측소 좌표와 `observed_at` |
| 해수욕장·항·어장 | 명칭·주소·좌표 | 가장 가까운 `coast_segment_id` |

경북 동해안을 포항·영덕·울진·울릉의 1~5km 해안 세그먼트로 나누고 모든 점·격자·시설을 세그먼트에 붙인다. 15분 환경자료를 시간·일 단위로 집계하고, 주간 해파리 라벨에는 예측 발표 이전의 값만 붙인다.

### 시간 누수 방지

- 주간보고에 이미 포함된 수온·전망을 같은 주의 예측 피처로 사용하지 않는다.
- `issued_at`, `valid_at`, `observed_at`, `ingested_at`을 분리한다.
- 예보와 실측을 같은 컬럼에 덮어쓰지 않는다.
- 이후 수정된 특보를 당시 알려졌던 사실처럼 백테스트하지 않는다.

### 관측 노력 편향

- “미출현”과 “관측하지 않음”을 분리한다.
- 조사 선박 항로 길이, 설문 응답자 수, 신고 수를 관측 노력량으로 저장한다.
- 해수욕장·항 주변 신고가 많은 것을 해파리 생물량이 많다고 곧바로 해석하지 않는다.

## 7. 제품 후보 순위

| 순위 | 후보 | 판단 |
| ---: | --- | --- |
| 1 | 경북 동해안 해파리 도착시간·행동 큐 | NIFS 현재 라벨과 ROMS 이동 예측을 직접 행동으로 연결할 수 있음 |
| 2 | 신고 신뢰도·관측 공백 관리자 | 시민·어업인 신고를 공식 관측과 결합해 다음 조사 위치를 결정함 |
| 3 | 폴립 제거·구제 우선순위 | 과거 출현과 제거 좌표로 현장 검증 위치를 고를 수 있음 |
| 4 | 해수욕장 운영 보조 | 구현은 쉽지만 실시간 방문·통제·사고 데이터가 없어 알림 지도 위험이 큼 |
| 5 | 해파리 자원화 공급 예측 | 흥미롭지만 수거량·품질·수요·처리비용 공개데이터가 없어 체인이 끊김 |

### 7.1 최종 권장 — 해파리 도착시간·행동 큐

```text
NIFS 경북 종별 출현률·출현지점
        +
ROMS 표층 유향·유속·수온
        +
조류·파랑·조석·염분
        +
종별 독성·쏘임 증상
        +
해수욕장·항·어업 노출 지점
        ↓
경북 동해안 세그먼트별 6·12·24·48시간 접근 가능성
        ↓
해수욕장 안전망 점검·현장 표본조사·어업인 확인 요청 순번
```

출력 예시:

- “노무라입깃해파리 관측과 표층 흐름이 유지되면 18~30시간 내 영덕 남부 연안 접근 가능성이 높음.”
- “A 해수욕장 안전망·구급함 확인을 1순위로 배정.”
- “B항 정치망 어업인에게 출현 여부 확인 요청.”
- “공식 특보 전 단계이며 모델 오차가 크므로 현장 확인 후 운영 결정을 승인.”

직접 사용자:

- 경북·시군 해양수산 담당자
- 국립수산과학원 모니터링 담당자
- 해수욕장 운영자와 어촌계

측정 지표:

- 예측 도착시간과 최초 공식·현장 확인시간의 오차
- 경보부터 현장 확인까지의 시간
- 고위험 세그먼트 조사 커버율
- 잘못된 출동·점검 횟수
- 조치 요청 완료율

안전 경계:

- 공식 특보나 입욕 통제를 자동 대체하지 않는다.
- 단일 도착시각 대신 확률 구간과 근거·데이터 시각을 표시한다.
- 모델이 낮은 위험을 제시해도 공식 특보를 하향하지 않는다.

### 7.2 신고 신뢰도·관측 공백 관리자

`시민 신고 + 설문 응답 + 공식 주간보고 + 수온·유속`을 이용해 다음을 수행한다.

- 같은 시공간의 중복 신고를 군집화
- 공식 관측이 드문 해안 구간을 탐지
- 해양환경과 일치하는 신고를 우선 현장 확인
- 다음 선박·드론·현장 관측 지점을 추천

효과는 신고 후 확인시간, 관측 공백 면적, 동일 자원으로 확인한 고위험 구간 수로 측정한다.

### 7.3 폴립 제거·구제 우선순위

`폴립 제거 좌표·수량 + 과거 출현보고·트롤밀도 + 현재 출현률 + 해류`를 연결한다.

- 반복 출현 해역과 제거 해역 비교
- 제거 전후의 관측 변화 탐색
- 다음 제거·조사 대상 정점 순위화
- 같은 비용으로 해수욕장·어업 노출을 많이 줄일 후보를 제시

연간 실적과 환경 변화만으로 인과효과를 단정하지 말고 “현장 검증 우선순위”라고 표현한다.

### 7.4 해수욕장 운영 보조

공식 출현률·종 독성·해류예측·해수욕장 위치·과거 이용객을 결합해 안전망·구급함·안내판 점검 순서를 만든다. 실시간 이용객·쏘임 사고·개방상태가 공개되지 않아 현재 데이터만으로 입욕 통제를 자동화할 수 없다.

### 7.5 해파리 자원화

식품·콜라겐·비료 등 자원화 아이디어는 흥미롭지만 공개데이터에서 다음이 발견되지 않았다.

- 해역·일자별 실제 수거량
- 종별 원료 품질과 오염·보관 상태
- 처리·냉장 물류비
- 구매·가공 수요자와 수요량
- 폐기 대비 자원화 성과

따라서 기관·기업 데이터가 확보되기 전에는 출현량 예측만 가능한 탐색 후보로 유지한다.

## 10. 사실·해석·미확정

### 확인된 사실

- 15147938은 55행의 정적 종 기준표다.
- NIFS 해파리정보 API는 주간 출현·수온·분포·변동·조치·전망을 제공한다고 명시한다.
- NIFS 공식 게시판은 2026년 8월에도 주간보고와 특보를 갱신하고 있다.
- 과거 출현보고는 36,826행이며 날짜·지역·위경도·크기·밀집여부가 있다.
- ROMS는 bbox별 표층 유향·유속·수온 예측값을 제공한다.
- 경북 해수욕장 이용객 데이터는 27개 해수욕장의 2008~2025 연간 수치다.

### 근거 기반 해석

- 가장 완결된 조합은 `NIFS 출현 라벨 + ROMS 이동 + 종 독성 + 노출 지점 + 행동 큐`다.
- 출현률은 절대 생물량이 아니라 관측자 응답 비율일 가능성이 높다.
- 해수욕장 안전보다 관측·점검 우선순위를 제품 행동으로 선택하면 공개데이터 공백과 안전 책임을 줄일 수 있다.

### 미확정

- NIFS 최신 상세 API의 실제 필드 충실도와 경북 값
- 분포도의 기계 판독 가능 여부
- ROMS 예측기간·공간해상도·경북 bbox 실제 응답량
- 경북 해수욕장 실시간 통제·쏘임 사고·구제 실적 데이터 존재 여부
- 자원화에 필요한 수거량·품질·수요 데이터 확보 가능성
