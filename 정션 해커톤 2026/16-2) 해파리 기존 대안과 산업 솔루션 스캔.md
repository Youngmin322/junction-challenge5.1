# 해파리 기존 대안과 산업 솔루션 스캔

> [!note] 읽는 법
> 경쟁사를 고르는 문서가 아니다. 사용자가 이미 채택할 수 있는 `아무것도 안 함·전화·육안·망·센서·예보·앱·절차`까지 대안으로 놓고, 새 후보가 실제로 무엇을 추가해야 하는지 보기 위한 지도다. 업체 페이지의 성능·절감 수치는 `상업적 주장`으로 표시한다.

### NIFS 해파리정보

- 기능: 종별·지역별 출현률, 분포, 주간변동, 전망, 조치·협조사항.
- 대체하는 것: 비공식 소문만으로 상황을 판단하는 문제.
- 남는 공백: 실제 API 최신행·결측 검증, 시설별 영향, 확인태스크, 사후 라벨.

### Torness Marine Ingress Weather Alert

- 기능: 풍향·파고·파향 기반 위험지표, 절차 흐름도, 상황실 계측, 스크린 보호·세척·레이킹.
- 의미: 1개 해외 시설에서 위험지표·절차·계측·설비조치를 결합한 구조가 운영된 공식 기록이 있다. 일반화 가능 여부와 효과량은 미확인이다.
- 남는 공백: 한국 데이터·시설별 검증, 효과량, 해파리/해조류 분리.
- 출처: [UK OSART](https://www.gov.uk/government/publications/operational-safety-review-torness-nuclear-power-station-2018-independent-report-and-government-response/osart-report-on-torness-nuclear-power-plant-2018).

### JellyMonitor

- 기능: 카메라와 초음파를 결합한 연안 해파리 자동탐지 센서 패키지.
- 상태: Innovate UK 지원 R&D는 완료로 표시되며, 수조→해안→발전소 장기설치의 3단계 시험 설계.
- 남는 공백: 이후 상용 배치·교차환경 정확도·가격 공개자료.
- 출처: [UKERC 프로젝트](https://ukerc9.rl.ac.uk/cgi-bin/ercri6.pl?GCatSum=2784&GChoose=gecatsum&GRN=InnUK%2F102072%2F01&GSumCat=06-01&HTC=5CF1C4CA&SHTC=555FE3E&SSHTC=239AB), [자동탐지 논문](https://research-portal.uea.ac.uk/files/142240782/jelly_monitor_icsp_v04.pdf).

### BioSonics intake monitoring

- 기능 주장: split-beam sonar로 debris·jellyfish·aquatic life 실시간 탐지·추적.
- 증거 표기: 업체가 국제 대형 발전소 배치를 주장하나 독립 성능·고객사·오탐 자료는 이번 조사에서 미확인.
- 출처: [BioSonics](https://www.biosonicsinc.com/solutions/watersidesafety/).

### EDF–Cranfield 드론 조기탐지

- 기능: UAV 고해상도 영상과 객체인식으로 발전소 접근 bloom을 탐지.
- 남는 공백: BVLOS·바람·구름·표층 가시성·실제 ETA 정확도.
- 출처: [Cranfield](https://www.cranfield.ac.uk/research-projects/drones-jellyfish), [EDF](https://www.edfenergy.com/energywise/drones-coastal-areas).

### SEAWATCH by Fugro

- 기능 주장: 위성·현장센서·자율선·모델을 결합해 조류·해파리·DO 등을 7일 예보하고 행동 알림.
- 증거 표기: 72시간 경고와 절감액은 업체 페이지의 상업적 주장. 해파리별 독립 검증은 미확인.
- 출처: [SEAWATCH](https://seawatch.ai/industries/aquaculture).

### FP Aqua PlanktonSensor

- 기능 주장: 수중 고해상도 현미경으로 sea lice·micro jellyfish 등 탐지, 여러 수심 측정.
- 상태: 데이터 플랫폼은 `under development`로 표기.
- 출처: [FP Aqua](https://www.fpaqua.com/aquaculture).

### JellySafe

- 기능: Apolemia 영상 AI, 위험예보, 양식장 유입방지 수단의 전면 실증.
- 차이: 소프트웨어만이 아니라 현장 보호기술과 결과 차이를 함께 연구.
- 출처: [SINTEF JellySafe](https://www.sintef.no/en/projects/2024/jellysafe/).

### 시민과학 제품군

- GelAvista: 포르투갈 해안·도서의 참여형 종·분포·동태 수집과 예측. [IPMA](https://gelavista.ipma.pt/en/sobre/)
- MedusApp: 양성·음성 관측, 쏘임 신고, 실시간 지도, 종·응급처치 가이드. 대학 페이지는 40만+ 다운로드와 4.1만 게시 관측을 소개. [UA](https://web.ua.es/en/marlabdenia/medusapp.html)
- MINKA/Medusa a la vista: 사진·위치 관측을 협업 검증하고 GBIF에 개방. [EU Citizen Science](https://citizenscience.eu/project/672)
- 의미: `시민 신고 지도`만으로는 새롭지 않다. 음성 신고, 검증, 개방 표준, 교육까지 이미 구현된 사례가 있다.

## 3. 경쟁이 아니라 조합 가능한 슬롯

- 공공 주간신호 + 민간 시설센서 + 시민 사진을 출처별로 섞지 않는 사건 규격
- 광역모델이 불확실할 때 드론·선박·시민에게 확인을 요청하는 능동검증
- 센서 업체의 경고를 시설 SOP와 사람 승인에 연결하는 중립 workflow
- 상업 예보의 성능 주장과 실제 사건 결과를 장기 추적하는 독립 평가
- JellySafe 같은 현장실증 결과를 한국 생물종·시설 맥락과 비교하는 증거 레지스트리

## 4. 조사 공백

- 한국 발전·담수화·양식 시설이 실제 구매·운영 중인 해파리 전용 센서 업체
- JellyMonitor의 프로젝트 종료 뒤 상용화·장기 현장 정확도
- BioSonics·SEAWATCH·BioProtect·FP Aqua의 가격, 오탐률, 교차지역 성능, 데이터 소유권
- NIFS 내부 예보 workflow와 지자체·시설까지의 실제 전달시간
- 물리 차단 장치별 비표적 생물영향·정비비·실패 모드
